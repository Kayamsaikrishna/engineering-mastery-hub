🚀 Why Bit Manipulation in C?

Definition

In C, bit manipulation is the foundation of embedded systems, driver development, and operating systems. You are directly controlling the CPU's registers.

Understanding the difference between signed and unsigned shifts is critical for writing portable code.

🔑 C Specifics:
  • No built-in binary print: You must write your own function to print bits.
  • Macros: Commonly used for setting/clearing bits (e.g., in microcontroller headers).
  • Undefined Behavior: Shifting by more than bit-width (e.g., 1 << 33 on 32-bit int) is UB.

2. Visualizing Binary in C (Manual)

C - Print Bits Function
#include <stdio.h> void printBits(int n) { for (int i = 31; i >= 0; i--) { // Shift bit i to position 0 and check if it's 1 int bit = (n >> i) & 1; printf("%d", bit); } printf("\n"); } int main() { printBits(5); // 000...0101 return 0; }

3. Important Macros

#define SET_BIT(n, pos) ((n) | (1U << (pos))) #define CLEAR_BIT(n, pos) ((n) & ~(1U << (pos))) #define CHECK_BIT(n, pos) (((n) & (1U << (pos))) != 0) #define TOGGLE_BIT(n, pos) ((n) ^ (1U << (pos)))

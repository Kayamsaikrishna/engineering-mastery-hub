🚀 What is a String in C?

Definition

In C, there is NO string type! A string is simply a one-dimensional array of characters terminated by a null character '\0'.

This simple definition gives you full control but requires careful memory management.

🔑 Key Insight: The '\0' (Null Terminator) marks the end of the string. Without it, functions like printf keeps reading memory until it crashes!

💡 Memory Trick: Always allocate length + 1 for the null terminator. To store "Hello" (5 chars), you need an array of size 6.

📚 String Basics in C

1. Creating Strings

C - String Creation
#include <stdio.h> #include <string.h> // Method 1: Character Array (Mutable) char s1[] = "Hello"; s1[0] = 'J'; // Valid -> "Jello" // Method 2: String Pointer (Read-Only Literal) char *s2 = "World"; // s2[0] = 'X'; // CRASH! Undefined behavior (modifying read-only memory) // Method 3: Sized Array (Buffer) char s3[20] = "Buffer"; // Size 20, holds "Buffer\0" // Method 4: Manual Chars char s4[] = {'C', 'o', 'd', 'e', '\0'}; // Must add \0 manually!
PSEUDOCODE: String Creation DECLARE char array s[SIZE] SET s = "Hello World" SET length = strlen(s)

2. Accessing Characters

C - Character Access
char s[] = "Language"; // Access by index char distinct = s[0]; // 'L' char last = s[strlen(s) - 1]; // 'e' // Iterate through characters // Method 1: Index Loop for (int i = 0; s[i] != '\0'; i++) { printf("%c ", s[i]); } // Method 2: Pointer Arithmetic char *ptr = s; while (*ptr != '\0') { printf("%c ", *ptr); ptr++; }
⚠️ Safety Tip: Always check for NULL pointers before accessing structure, although standard strings are usually arrays.

3. String Slicing (Substring)

Syntax: manual strncpy required

C has no built-in slice. You must copy characters to a new buffer.

C - Substrings
char s[] = "C Programming"; char sub[10]; // Extract "Prog" (Starts at index 2, length 4) strncpy(sub, s + 2, 4); sub[4] = '\0'; // MUST manually terminate! printf("%s", sub); // "Prog"
💡 Null Terminator Rule: strncpy does NOT add \0 automatically if max length is reached. YOU must add it.

4. String Mutability

C - Mutability
char s[] = "Hello"; // Modify character s[0] = 'J'; printf("%s", s); // "Jello" // WARNING: Can only modify arrays, NOT string literals (char *s = "...")

⚙️ Core String Operations in C

1. Concatenation (Joining Strings)

C - String Concatenation
#include <string.h> char s1[20] = "Hello"; // Must have enough space! char s2[] = " World"; // Method 1: strcat (Appends s2 to s1) strcat(s1, s2); printf("%s", s1); // "Hello World" // Method 2: strncat (Safe - Limit chars) strncat(s1, "!", 1);
⚠️ Buffer Overflow: strcat is dangerous! Does s1 have enough space? If not, program crashes or gets hacked. Use strncat safely.

2. String Copying

C - String Copy
char src[] = "Copy Me"; char dest[20]; // Copy src to dest strcpy(dest, src); // Safe Copy strncpy(dest, src, sizeof(dest) - 1); dest[sizeof(dest) - 1] = '\0'; // Ensure termination

3. String Comparison

C - Comparing Strings
char s1[] = "Apple"; char s2[] = "Banana"; // strcmp returns: // 0 if equal // <0 if s1 < s2 // >0 if s1 > s2 if (strcmp(s1, s2) == 0) { printf("Equal"); } else if (strcmp(s1, s2) < 0) { printf("s1 is smaller"); // Prints this } // Case-insensitive? Use strcasecmp (POSIX) or custom loop.

4. Searching in Strings

C - String Search
char s[] = "C Programming Language"; // Find substring (strstr) char *found = strstr(s, "Programming"); if (found != NULL) { printf("Found at index: %ld", found - s); // Pointer arithmetic for index } // Find character (strchr) char *c = strchr(s, 'P'); // Find last occurrence (strrchr) char *last = strrchr(s, 'a');

5. Key String Functions (string.h)

Function Description
strlen(s) Length of string (excluding \0)
strcpy(d, s) Copy string
strcat(d, s) Concatenate string
strcmp(s1, s2) Compare strings
strstr(s, sub) Find substring

🛠️ Essential String Functions in C

1. Case Conversion

C - Manual Uppercase
#include <ctype.h> char s[] = "Hello World"; // Convert to Uppercase (In-place) for (int i = 0; s[i] != '\0'; i++) { s[i] = toupper(s[i]); } printf("%s", s); // "HELLO WORLD" // To Lowercase for (int i = 0; s[i] != '\0'; i++) { s[i] = tolower(s[i]); }

2. String Tokenization (Splitting)

C - strtok (Destructive!)
char s[] = "Hello,World,C"; char *token; // First call: Pass the string token = strtok(s, ","); while (token != NULL) { printf("%s\n", token); // Subsequent calls: Pass NULL token = strtok(NULL, ","); } /* Output: Hello World C */ // WARNING: strtok modifies the original string by inserting \0

3. String/Number Conversion

C - Formatting
// String to Number int num = atoi("123"); double d = atof("3.14"); // Number to String (sprintf) char buffer[50]; int age = 25; sprintf(buffer, "Age: %d", age); printf("%s", buffer); // "Age: 25"

🎨 Common String Patterns

Pattern 1: Character Frequency Count

C - Frequency Array
char s[] = "hello world"; int freq[256] = {0}; // Initialize to 0 for (int i = 0; s[i] != '\0'; i++) { freq[(unsigned char)s[i]]++; } // Print non-zero frequencies for (int i = 0; i < 256; i++) { if (freq[i] > 0) { printf("%c: %d\n", i, freq[i]); } }
PSEUDOCODE: Character Frequency Time Complexity: O(n) Space Complexity: O(1) (Fixed size 256)

Pattern 2: Palindrome Check

C - Palindrome
int isPalindrome(char *s) { int left = 0; int right = strlen(s) - 1; while (left < right) { if (s[left] != s[right]) return 0; // False left++; right--; } return 1; // True }

Pattern 3: Anagram Check

C - Anagram Detection
int isAnagram(char *s1, char *s2) { if (strlen(s1) != strlen(s2)) return 0; int count[256] = {0}; for (int i = 0; s1[i] != '\0'; i++) count[(unsigned char)s1[i]]++; for (int i = 0; s2[i] != '\0'; i++) count[(unsigned char)s2[i]]--; for (int i = 0; i < 256; i++) { if (count[i] != 0) return 0; } return 1; }

Pattern 4: Substring Search

C - Find All Occurrences
char text[] = "banana"; char *p = text; char *pattern = "an"; while ((p = strstr(p, pattern)) != NULL) { printf("Found at index: %ld\n", p - text); p++; // Advance past found match }

🎯 Key Takeaways to Remember Forever

The 10 Commandments of Strings:
  1. Immutable: Can't change, only create new strings
  2. Zero-indexed: First character at index 0
  3. Slicing is exclusive: s[1:4] = indices 1, 2, 3
  4. Use join() not +: For concatenating multiple strings
  5. Case matters: "Hello" != "hello"
  6. f-strings are best: For formatting in Python 3.6+
  7. in operator: Fast substring/character checking
  8. Reverse with [::-1]: Simplest way to reverse
  9. Count frequency: Use Counter or dictionary
  10. Validate input: Check length and bounds

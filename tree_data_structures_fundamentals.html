🚀 Introduction to Trees

What is a Tree?

A Tree is a hierarchical data structure consisting of nodes connected by edges. It has a root node at the top and branches down to child nodes. Unlike linear data structures (arrays, linked lists), trees organize data in a parent-child hierarchy.

Basic Tree Structure

           1  ← Root
          /|\
         / | \
        2  3  4  ← Children of 1
       /\     |
      5  6    7  ← Leaf nodes (no children)

Tree Terminology

  • Root: Top node with no parent
  • Parent: Node with children below it
  • Child: Node with a parent above it
  • Leaf: Node with no children
  • Edge: Connection between two nodes
  • Path: Sequence of nodes from one node to another
  • Height: Longest path from root to leaf
  • Depth/Level: Distance from root to node
  • Subtree: Tree formed by a node and its descendants
  • Siblings: Nodes with same parent
💡 Memory Trick: Tree = Family Tree
  • Root = Ancestor at top
  • Parent/Child = Family relationships
  • Leaf = People with no children
  • Siblings = Brothers/sisters
  • Height = Generations deep

Why Use Trees?

  • Hierarchical Data: File systems, organization charts, DOM
  • Fast Search: BST provides O(log n) search
  • Sorted Data: In-order traversal of BST gives sorted output
  • Priority Handling: Heaps for priority queues
  • Efficient Insertions: Better than sorted arrays
  • Database Indexing: B-trees in databases
  • Autocomplete: Tries for prefix matching

Types of Trees

Tree Type Key Property Use Case
Binary Tree Max 2 children per node Expression trees, decision trees
Binary Search Tree Left < Root < Right (ordered) Fast search, sorted data
AVL Tree Self-balancing BST When balance is critical
Trie Prefix tree for strings Autocomplete, dictionary
Heap Complete tree, parent ≥/≤ children Priority queue, heap sort
N-ary Tree N children per node File systems, org charts

Tree Properties

  • Number of nodes: n
  • Number of edges: n - 1 (always one less than nodes)
  • Max nodes at level L: 2^L (for binary tree)
  • Max nodes with height H: 2^(H+1) - 1
  • Min height for n nodes: log₂(n+1) - 1

Tree Traversals

Depth-First Search (DFS):

  • Inorder (Left-Root-Right): Gets sorted order in BST
  • Preorder (Root-Left-Right): Good for copying tree
  • Postorder (Left-Right-Root): Good for deleting tree

Breadth-First Search (BFS):

  • Level-order: Visit nodes level by level (use queue)

Example Tree for Traversals

       1
      / \
     2   3
    / \
   4   5

Inorder:   4, 2, 5, 1, 3
Preorder:  1, 2, 4, 5, 3
Postorder: 4, 5, 2, 3, 1
Level-order: 1, 2, 3, 4, 5

🌲 Binary Tree

Definition

A Binary Tree is a tree where each node has at most 2 children: left child and right child. No ordering constraint - values can be anywhere.

Types of Binary Trees

  1. Full Binary Tree: Every node has 0 or 2 children
  2. Complete Binary Tree: All levels filled except possibly last, which is filled left-to-right
  3. Perfect Binary Tree: All internal nodes have 2 children, all leaves at same level
  4. Balanced Binary Tree: Height difference of left and right subtrees ≤ 1
  5. Degenerate/Skewed Tree: Each node has only one child (essentially a linked list)

Implementation

Python - Binary Tree Node
class TreeNode: """Node for binary tree""" def __init__(self, val): self.val = val self.left = None self.right = None # Creating a binary tree: # 1 # / \ # 2 3 # / \ # 4 5 root = TreeNode(1) root.left = TreeNode(2) root.right = TreeNode(3) root.left.left = TreeNode(4) root.left.right = TreeNode(5)

Tree Traversals

Python - DFS Traversals
def inorder(root): """ Left -> Root -> Right Time: O(n), Space: O(h) where h is height """ if not root: return [] result = [] result.extend(inorder(root.left)) result.append(root.val) result.extend(inorder(root.right)) return result def preorder(root): """ Root -> Left -> Right """ if not root: return [] result = [root.val] result.extend(preorder(root.left)) result.extend(preorder(root.right)) return result def postorder(root): """ Left -> Right -> Root """ if not root: return [] result = [] result.extend(postorder(root.left)) result.extend(postorder(root.right)) result.append(root.val) return result # Example usage print(inorder(root)) # [4, 2, 5, 1, 3] print(preorder(root)) # [1, 2, 4, 5, 3] print(postorder(root)) # [4, 5, 2, 3, 1]
Python - BFS (Level Order)
from collections import deque def level_order(root): """ BFS traversal - visit level by level Time: O(n), Space: O(w) where w is max width """ if not root: return [] result = [] queue = deque([root]) while queue: node = queue.popleft() result.append(node.val) if node.left: queue.append(node.left) if node.right: queue.append(node.right) return result print(level_order(root)) # [1, 2, 3, 4, 5]

Common Operations

Python - Binary Tree Operations
def height(root): """Height of tree""" if not root: return -1 return 1 + max(height(root.left), height(root.right)) def count_nodes(root): """Count total nodes""" if not root: return 0 return 1 + count_nodes(root.left) + count_nodes(root.right) def max_value(root): """Find maximum value in tree""" if not root: return float('-inf') return max(root.val, max_value(root.left), max_value(root.right)) def is_balanced(root): """Check if tree is balanced""" def check_height(node): if not node: return 0 left_height = check_height(node.left) if left_height == -1: return -1 right_height = check_height(node.right) if right_height == -1: return -1 if abs(left_height - right_height) > 1: return -1 return 1 + max(left_height, right_height) return check_height(root) != -1 # Usage print(f"Height: {height(root)}") # 2 print(f"Node count: {count_nodes(root)}") # 5 print(f"Max value: {max_value(root)}") # 5 print(f"Balanced: {is_balanced(root)}") # True
Binary Tree Time Complexities:
  • Traversal: O(n) - visit all nodes
  • Search: O(n) - may need to check all nodes
  • Insert/Delete: O(n) - may need to find location
  • Height: O(n) - calculate recursively

🔍 Binary Search Tree (BST)

Definition

A Binary Search Tree is a binary tree with ordering property:

  • Left subtree contains values less than root
  • Right subtree contains values greater than root
  • Both subtrees are also BSTs (recursive property)

Valid BST Example

       8
      / \
     3   10
    / \    \
   1   6   14
      / \  /
     4  7 13

Left subtree (3,1,6,4,7) < 8
Right subtree (10,14,13) > 8
🔑 Key Advantage: BST enables O(log n) search in balanced tree! Like binary search on sorted array, but with efficient insertions.

BST Operations

Python - BST Implementation
class BST: """Binary Search Tree""" def __init__(self): self.root = None def insert(self, val): """Insert value - O(h) where h is height""" self.root = self._insert_recursive(self.root, val) def _insert_recursive(self, node, val): if not node: return TreeNode(val) if val < node.val: node.left = self._insert_recursive(node.left, val) elif val > node.val: node.right = self._insert_recursive(node.right, val) # If equal, don't insert (or handle duplicates as needed) return node def search(self, val): """Search for value - O(h)""" return self._search_recursive(self.root, val) def _search_recursive(self, node, val): if not node or node.val == val: return node if val < node.val: return self._search_recursive(node.left, val) else: return self._search_recursive(node.right, val) def delete(self, val): """Delete value - O(h)""" self.root = self._delete_recursive(self.root, val) def _delete_recursive(self, node, val): if not node: return None if val < node.val: node.left = self._delete_recursive(node.left, val) elif val > node.val: node.right = self._delete_recursive(node.right, val) else: # Found node to delete # Case 1: No children (leaf) if not node.left and not node.right: return None # Case 2: One child if not node.left: return node.right if not node.right: return node.left # Case 3: Two children # Find inorder successor (min in right subtree) min_node = self._find_min(node.right) node.val = min_node.val node.right = self._delete_recursive(node.right, min_node.val) return node def _find_min(self, node): """Find minimum value node""" while node.left: node = node.left return node def inorder(self): """Inorder gives sorted output""" result = [] self._inorder_recursive(self.root, result) return result def _inorder_recursive(self, node, result): if node: self._inorder_recursive(node.left, result) result.append(node.val) self._inorder_recursive(node.right, result) # Example usage bst = BST() values = [8, 3, 10, 1, 6, 14, 4, 7, 13] for val in values: bst.insert(val) print(bst.inorder()) # [1, 3, 4, 6, 7, 8, 10, 13, 14] - sorted! print(bst.search(6)) # Found bst.delete(3) print(bst.inorder()) # [1, 4, 6, 7, 8, 10, 13, 14]

BST Validation

Python - Validate BST
def is_valid_bst(root, min_val=float('-inf'), max_val=float('inf')): """ Check if tree is valid BST All nodes in left subtree must be < root All nodes in right subtree must be > root """ if not root: return True # Check current node's value range if root.val <= min_val or root.val >= max_val: return False # Check left and right subtrees return (is_valid_bst(root.left, min_val, root.val) and is_valid_bst(root.right, root.val, max_val)) # This catches subtle errors like: # 5 # / \ # 1 6 # / \ # 4 7 <- 4 < 5, invalid!

Common BST Problems

Python - BST Problems
def find_kth_smallest(root, k): """Find kth smallest element (inorder traversal)""" result = [0] count = [0] def inorder(node): if not node or result[0]: return inorder(node.left) count[0] += 1 if count[0] == k: result[0] = node.val return inorder(node.right) inorder(root) return result[0] def lowest_common_ancestor(root, p, q): """ Find LCA in BST Use BST property for efficient solution """ if not root: return None # If both p and q are smaller, LCA is in left if p.val < root.val and q.val < root.val: return lowest_common_ancestor(root.left, p, q) # If both p and q are greater, LCA is in right if p.val > root.val and q.val > root.val: return lowest_common_ancestor(root.right, p, q) # We found the split point return root def bst_to_sorted_array(root): """Convert BST to sorted array (inorder)""" result = [] def inorder(node): if node: inorder(node.left) result.append(node.val) inorder(node.right) inorder(root) return result
Operation Average Case Worst Case Notes
Search O(log n) O(n) Worst when tree is skewed
Insert O(log n) O(n) Worst when tree is skewed
Delete O(log n) O(n) Need to find node first
Inorder O(n) O(n) Gives sorted output
⚠️ BST Degenerates: If we insert sorted data (1,2,3,4,5...), BST becomes a linked list! All operations become O(n). Solution: Use self-balancing trees like AVL.

⚖️ AVL Tree (Self-Balancing BST)

Definition

An AVL Tree is a self-balancing BST where the heights of left and right subtrees differ by at most 1 for every node. Named after inventors Adelson-Velsky and Landis.

Balance Factor: BF = Height(Left Subtree) - Height(Right Subtree)
For AVL tree: BF ∈ {-1, 0, 1} for all nodes

Rotations

AVL maintains balance through rotations:

  • Left Rotation (LL): Right subtree too heavy
  • Right Rotation (RR): Left subtree too heavy
  • Left-Right Rotation (LR): Left then right
  • Right-Left Rotation (RL): Right then left
Python - AVL Tree Implementation
class AVLNode: def __init__(self, val): self.val = val self.left = None self.right = None self.height = 1 # Height of node class AVLTree: def __init__(self): self.root = None def height(self, node): """Get height of node""" if not node: return 0 return node.height def balance_factor(self, node): """Calculate balance factor""" if not node: return 0 return self.height(node.left) - self.height(node.right) def update_height(self, node): """Update height of node""" if node: node.height = 1 + max(self.height(node.left), self.height(node.right)) def rotate_right(self, z): """ Right rotation z y / \ / \ y T4 --> x z / \ / \ x T3 T3 T4 """ y = z.left T3 = y.right # Perform rotation y.right = z z.left = T3 # Update heights self.update_height(z) self.update_height(y) return y def rotate_left(self, z): """ Left rotation z y / \ / \ T1 y --> z x / \ / \ T2 x T1 T2 """ y = z.right T2 = y.left # Perform rotation y.left = z z.right = T2 # Update heights self.update_height(z) self.update_height(y) return y def insert(self, val): """Insert value and rebalance""" self.root = self._insert(self.root, val) def _insert(self, node, val): # Standard BST insert if not node: return AVLNode(val) if val < node.val: node.left = self._insert(node.left, val) elif val > node.val: node.right = self._insert(node.right, val) else: return node # Duplicate # Update height self.update_height(node) # Get balance factor bf = self.balance_factor(node) # Left-Left Case if bf > 1 and val < node.left.val: return self.rotate_right(node) # Right-Right Case if bf < -1 and val > node.right.val: return self.rotate_left(node) # Left-Right Case if bf > 1 and val > node.left.val: node.left = self.rotate_left(node.left) return self.rotate_right(node) # Right-Left Case if bf < -1 and val < node.right.val: node.right = self.rotate_right(node.right) return self.rotate_left(node) return node def inorder(self): """Inorder traversal""" result = [] self._inorder(self.root, result) return result def _inorder(self, node, result): if node: self._inorder(node.left, result) result.append(node.val) self._inorder(node.right, result) # Example - insert sorted data (would break regular BST) avl = AVLTree() for i in range(1, 8): avl.insert(i) print(avl.inorder()) # Still balanced! print(f"Height: {avl.height(avl.root)}") # Only 3 (vs 7 for skewed BST)
Operation AVL Tree Regular BST
Search O(log n) guaranteed O(n) worst case
Insert O(log n) guaranteed O(n) worst case
Delete O(log n) guaranteed O(n) worst case
Height Always O(log n) Can be O(n)
When to use AVL:
  • ✅ Need guaranteed O(log n) operations
  • ✅ Search-heavy applications
  • ✅ Cannot tolerate worst-case O(n)
  • ❌ Frequent insertions/deletions (rotations add overhead)

📝 Trie (Prefix Tree)

Definition

A Trie is a tree data structure for storing strings where each node represents a character. Common prefixes share the same path. Excellent for prefix matching and autocomplete.

Trie Structure for ["cat", "car", "card", "dog"]

         root
        /    \
       c      d
       |      |
       a      o
      / \     |
     t   r    g*
    *    |
         d*

* marks end of word

Python - Trie Implementation
class TrieNode: def __init__(self): self.children = {} # Map char -> TrieNode self.is_end_of_word = False class Trie: def __init__(self): self.root = TrieNode() def insert(self, word): """ Insert word into trie Time: O(m) where m is word length """ node = self.root for char in word: if char not in node.children: node.children[char] = TrieNode() node = node.children[char] node.is_end_of_word = True def search(self, word): """ Search for exact word Time: O(m) """ node = self.root for char in word: if char not in node.children: return False node = node.children[char] return node.is_end_of_word def starts_with(self, prefix): """ Check if any word starts with prefix Time: O(m) """ node = self.root for char in prefix: if char not in node.children: return False node = node.children[char] return True def get_all_words_with_prefix(self, prefix): """ Get all words starting with prefix (autocomplete) """ node = self.root # Navigate to prefix for char in prefix: if char not in node.children: return [] node = node.children[char] # Collect all words from this point words = [] self._collect_words(node, prefix, words) return words def _collect_words(self, node, current_word, words): """Helper to collect words recursively""" if node.is_end_of_word: words.append(current_word) for char, child_node in node.children.items(): self._collect_words(child_node, current_word + char, words) def delete(self, word): """Delete word from trie""" def _delete(node, word, index): if index == len(word): if not node.is_end_of_word: return False node.is_end_of_word = False return len(node.children) == 0 char = word[index] if char not in node.children: return False child = node.children[char] should_delete_child = _delete(child, word, index + 1) if should_delete_child: del node.children[char] return len(node.children) == 0 and not node.is_end_of_word return False _delete(self.root, word, 0) # Example usage trie = Trie() words = ["apple", "app", "apricot", "banana", "band"] for word in words: trie.insert(word) print(trie.search("app")) # True print(trie.search("appl")) # False print(trie.starts_with("app")) # True print(trie.get_all_words_with_prefix("ap")) # ['app', 'apple', 'apricot'] print(trie.get_all_words_with_prefix("ban")) # ['banana', 'band']

Trie Applications

  • Autocomplete: Type "ap" → suggest "apple", "app", "apricot"
  • Spell Checker: Check if word exists in dictionary
  • IP Routing: Longest prefix matching
  • T9 Predictive Text: Phone keyboards
  • Genome Analysis: DNA sequence matching
  • Search Engines: Query suggestions
Operation Time Complexity Notes
Insert O(m) m = word length
Search O(m) Faster than hash for prefix queries
Prefix Search O(m) Key advantage over hash table
Space O(ALPHABET_SIZE × m × n) n = number of words
Trie vs Hash Table:
  • Trie wins: Prefix searches, sorted order, memory efficiency for common prefixes
  • Hash wins: Simple lookups, less memory overhead

📊 Heap & Priority Queue

What is a Heap?

A Heap is a complete binary tree that satisfies the heap property:

  • Max Heap: Parent ≥ all children (root is maximum)
  • Min Heap: Parent ≤ all children (root is minimum)

Max Heap Example

       100
       / \
     50   30
    / \   /
   20 10 5

Parent always ≥ children
Root = maximum element
🔑 Key Properties:
  • Complete binary tree (filled left-to-right)
  • Can be efficiently stored in array
  • Parent at index i, children at 2i+1 and 2i+2
  • O(1) access to min/max element

Heap as Array

Heap [100, 50, 30, 20, 10, 5]

  • Parent(i) = (i-1) // 2
  • Left Child(i) = 2*i + 1
  • Right Child(i) = 2*i + 2
Python - Min Heap Implementation
class MinHeap: def __init__(self): self.heap = [] def parent(self, i): return (i - 1) // 2 def left_child(self, i): return 2 * i + 1 def right_child(self, i): return 2 * i + 2 def swap(self, i, j): self.heap[i], self.heap[j] = self.heap[j], self.heap[i] def insert(self, val): """ Insert and bubble up Time: O(log n) """ self.heap.append(val) self._bubble_up(len(self.heap) - 1) def _bubble_up(self, i): """Move element up to maintain heap property""" parent = self.parent(i) if i > 0 and self.heap[i] < self.heap[parent]: self.swap(i, parent) self._bubble_up(parent) def extract_min(self): """ Remove and return minimum (root) Time: O(log n) """ if not self.heap: return None if len(self.heap) == 1: return self.heap.pop() # Store root min_val = self.heap[0] # Move last element to root self.heap[0] = self.heap.pop() # Bubble down self._bubble_down(0) return min_val def _bubble_down(self, i): """Move element down to maintain heap property""" min_index = i left = self.left_child(i) right = self.right_child(i) # Find smallest among node and children if left < len(self.heap) and self.heap[left] < self.heap[min_index]: min_index = left if right < len(self.heap) and self.heap[right] < self.heap[min_index]: min_index = right # Swap if needed and continue if min_index != i: self.swap(i, min_index) self._bubble_down(min_index) def peek(self): """Get minimum without removing""" return self.heap[0] if self.heap else None def size(self): return len(self.heap) def is_empty(self): return len(self.heap) == 0 # Example usage min_heap = MinHeap() values = [5, 3, 7, 1, 9, 2] for val in values: min_heap.insert(val) print("Extracting in sorted order:") while not min_heap.is_empty(): print(min_heap.extract_min(), end=" ") # 1 2 3 5 7 9

Priority Queue using Heap

Python - Priority Queue
import heapq class PriorityQueue: """ Priority Queue using heapq (min heap) Lower number = higher priority """ def __init__(self): self.heap = [] self.counter = 0 # For tie-breaking def push(self, item, priority): """Add item with priority""" # Use counter to break ties (FIFO for same priority) heapq.heappush(self.heap, (priority, self.counter, item)) self.counter += 1 def pop(self): """Remove and return highest priority item""" if self.heap: return heapq.heappop(self.heap)[2] return None def peek(self): """View highest priority item""" if self.heap: return self.heap[0][2] return None def is_empty(self): return len(self.heap) == 0 # Example - Task scheduler pq = PriorityQueue() pq.push("Critical bug fix", 1) pq.push("Feature request", 3) pq.push("Security patch", 1) pq.push("Documentation", 5) print("Processing tasks by priority:") while not pq.is_empty(): print(pq.pop()) # Output: Critical bug fix, Security patch, Feature request, Documentation

Heap Applications

  • Heap Sort: O(n log n) sorting algorithm
  • Priority Queue: Task scheduling, Dijkstra's algorithm
  • K Largest/Smallest: Find k largest elements efficiently
  • Median Maintenance: Running median using two heaps
  • Merge K Sorted Lists: Efficient merging
  • Event-Driven Simulation: Next event scheduling
Operation Time Complexity
Get Min/Max O(1)
Insert O(log n)
Extract Min/Max O(log n)
Build Heap O(n)
Heapify O(log n)

🌴 N-ary Tree

Definition

An N-ary Tree is a tree where each node can have up to N children. Unlike binary trees (max 2 children), N-ary trees are more flexible.

N-ary Tree Example (N=3)

         1
      / | \
     2  3  4
    /|  |  |\
   5 6  7  8 9
Python - N-ary Tree Implementation
class NaryNode: def __init__(self, val): self.val = val self.children = [] # List of children class NaryTree: def __init__(self, root=None): self.root = root def preorder(self, node): """ Preorder: Root -> Children Time: O(n) """ if not node: return [] result = [node.val] for child in node.children: result.extend(self.preorder(child)) return result def postorder(self, node): """ Postorder: Children -> Root """ if not node: return [] result = [] for child in node.children: result.extend(self.postorder(child)) result.append(node.val) return result def level_order(self, root): """BFS traversal""" if not root: return [] from collections import deque result = [] queue = deque([root]) while queue: node = queue.popleft() result.append(node.val) for child in node.children: queue.append(child) return result def max_depth(self, node): """Find maximum depth""" if not node: return 0 if not node.children: return 1 max_child_depth = max(self.max_depth(child) for child in node.children) return 1 + max_child_depth # Build tree root = NaryNode(1) root.children = [NaryNode(2), NaryNode(3), NaryNode(4)] root.children[0].children = [NaryNode(5), NaryNode(6)] root.children[1].children = [NaryNode(7)] root.children[2].children = [NaryNode(8), NaryNode(9)] tree = NaryTree(root) print("Preorder:", tree.preorder(root)) # [1,2,5,6,3,7,4,8,9] print("Postorder:", tree.postorder(root)) # [5,6,2,7,3,8,9,4,1] print("Level order:", tree.level_order(root)) # [1,2,3,4,5,6,7,8,9] print("Max depth:", tree.max_depth(root)) # 3

N-ary Tree Applications

  • File Systems: Directories can have multiple files/subdirectories
  • Organization Charts: Manager with multiple direct reports
  • DOM Tree: HTML elements with multiple children
  • Game Trees: Move possibilities in games
  • XML/JSON Parsing: Nested structures
  • Compiler AST: Abstract syntax trees
Python - N-ary Tree Problems
def diameter(root): """ Find diameter (longest path between any two nodes) """ max_diameter = [0] def height(node): if not node: return 0 # Get heights of all children heights = [height(child) for child in node.children] # Diameter through this node if len(heights) >= 2: # Two tallest subtrees heights.sort(reverse=True) diameter_through_node = heights[0] + heights[1] max_diameter[0] = max(max_diameter[0], diameter_through_node) return 1 + (max(heights) if heights else 0) height(root) return max_diameter[0] def serialize(root): """Serialize N-ary tree to string""" if not root: return "" result = [str(root.val)] result.append(str(len(root.children))) for child in root.children: result.append(serialize(child)) return ",".join(result) def count_nodes(root): """Count total nodes in N-ary tree""" if not root: return 0 count = 1 for child in root.children: count += count_nodes(child) return count

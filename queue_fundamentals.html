🚀 What is a Queue?

Definition

A Queue is a linear data structure that follows the FIFO (First In, First Out) principle. The first element added is the first one to be removed.

Enqueue adds to rear, Dequeue removes from front

🔑 Critical Insight: Queue is FIFO - like a line at a ticket counter. First person in line gets served first!

Why Learn Queues?

  • Fundamental: Used in scheduling, buffering, breadth-first search
  • Interview Essential: Common in algorithm problems
  • Real-World: Print queue, task scheduling, message queues
  • Algorithm Building Block: BFS, level-order traversal, caching
  • System Design: Request handling, event processing
💡 Memory Trick: Queue = Line at Store
  • First person joins line (ENQUEUE at rear)
  • First person gets served and leaves (DEQUEUE from front)
  • New people join at the back
  • People leave from the front
  • First In, First Out (FIFO)

Core Operations

Operation Description Time Complexity
enqueue(item) Add item to rear of queue O(1)
dequeue() Remove and return front item O(1)
peek()/front() Return front item without removing O(1)
isEmpty() Check if queue is empty O(1)
size() Return number of elements O(1)

Queue vs Stack

Feature Queue Stack
Principle FIFO (First In First Out) LIFO (Last In First Out)
Add Rear (enqueue) Top (push)
Remove Front (dequeue) Top (pop)
Access Front only Top only
Use Case BFS, scheduling, buffering DFS, undo, recursion
Analogy Line at store Stack of plates

Real-World Examples

Where Queues Are Used:

  • Print Queue: Documents print in order received
  • CPU Scheduling: Processes wait in queue for execution
  • Breadth-First Search: Level-by-level tree/graph traversal
  • Message Queues: RabbitMQ, Kafka for async processing
  • Call Center: Customers wait in queue for next agent
  • Keyboard Buffer: Keystrokes stored in queue
  • Network Packets: Routers use queues for traffic

💻 Queue Implementation

1. Using Python List (Simple)

Simple but inefficient - dequeue is O(n) because removing from front shifts all elements.

Python - Queue Using List (Not Recommended)
class QueueList: """ Queue using Python list PROBLEM: dequeue is O(n) due to shifting """ def __init__(self): self.items = [] def enqueue(self, item): """Add to rear - O(1)""" self.items.append(item) def dequeue(self): """Remove from front - O(n)""" if self.is_empty(): raise IndexError("Queue is empty") return self.items.pop(0) # O(n) - BAD! def peek(self): """View front element""" if self.is_empty(): raise IndexError("Queue is empty") return self.items[0] def is_empty(self): return len(self.items) == 0 def size(self): return len(self.items) # Example queue = QueueList() queue.enqueue(10) queue.enqueue(20) queue.enqueue(30) print(queue.dequeue()) # 10 (FIFO)

2. Using collections.deque (Best)

Recommended! Both enqueue and dequeue are O(1). Deque = Double-Ended Queue

Python - Queue Using deque (BEST)
from collections import deque class Queue: """ Queue using collections.deque ALL operations O(1) - EFFICIENT! """ def __init__(self): self.items = deque() def enqueue(self, item): """Add to rear - O(1)""" self.items.append(item) def dequeue(self): """Remove from front - O(1)""" if self.is_empty(): raise IndexError("Queue is empty") return self.items.popleft() # O(1) - GOOD! def peek(self): """View front element""" if self.is_empty(): raise IndexError("Queue is empty") return self.items[0] def is_empty(self): return len(self.items) == 0 def size(self): return len(self.items) def __str__(self): return str(list(self.items)) # Example queue = Queue() queue.enqueue(10) queue.enqueue(20) queue.enqueue(30) print(queue) # [10, 20, 30] print(queue.dequeue()) # 10 print(queue.peek()) # 20 print(queue.size()) # 2
PSEUDOCODE: Queue Class CLASS Queue: CONSTRUCTOR(): items = deque() FUNCTION enqueue(item): APPEND item to items END FUNCTION FUNCTION dequeue(): IF isEmpty(): RAISE error "Queue is empty" END IF RETURN REMOVE_FIRST(items) END FUNCTION FUNCTION peek(): IF isEmpty(): RAISE error "Queue is empty" END IF RETURN items[0] END FUNCTION FUNCTION isEmpty(): RETURN LENGTH(items) == 0 END FUNCTION FUNCTION size(): RETURN LENGTH(items) END FUNCTION END CLASS All operations: O(1) time complexity

3. Using Linked List

Python - Queue Using Linked List
class Node: """Node for linked list""" def __init__(self, data): self.data = data self.next = None class QueueLinkedList: """ Queue using linked list Efficient O(1) operations, no fixed size """ def __init__(self): self.front = None # Remove from here self.rear = None # Add to here self._size = 0 def enqueue(self, item): """Add to rear""" new_node = Node(item) if self.rear is None: # Queue was empty self.front = self.rear = new_node else: self.rear.next = new_node self.rear = new_node self._size += 1 def dequeue(self): """Remove from front""" if self.is_empty(): raise IndexError("Queue is empty") item = self.front.data self.front = self.front.next if self.front is None: # Queue is now empty self.rear = None self._size -= 1 return item def peek(self): """View front element""" if self.is_empty(): raise IndexError("Queue is empty") return self.front.data def is_empty(self): return self.front is None def size(self): return self._size # Example queue = QueueLinkedList() queue.enqueue(10) queue.enqueue(20) queue.enqueue(30) print(queue.dequeue()) # 10 print(queue.peek()) # 20

4. Circular Queue (Fixed Size)

Circular Queue: Fixed-size array where rear wraps around to beginning. Efficient use of space.

Python - Circular Queue
class CircularQueue: """ Circular Queue with fixed size Efficient space usage, no shifting needed """ def __init__(self, capacity): self.capacity = capacity self.items = [None] * capacity self.front = 0 self.rear = -1 self._size = 0 def enqueue(self, item): """Add to rear""" if self.is_full(): raise OverflowError("Queue is full") self.rear = (self.rear + 1) % self.capacity # Wrap around self.items[self.rear] = item self._size += 1 def dequeue(self): """Remove from front""" if self.is_empty(): raise IndexError("Queue is empty") item = self.items[self.front] self.items[self.front] = None # Clear reference self.front = (self.front + 1) % self.capacity # Wrap around self._size -= 1 return item def peek(self): """View front element""" if self.is_empty(): raise IndexError("Queue is empty") return self.items[self.front] def is_empty(self): return self._size == 0 def is_full(self): return self._size == self.capacity def size(self): return self._size # Example queue = CircularQueue(5) queue.enqueue(10) queue.enqueue(20) queue.enqueue(30) print(queue.dequeue()) # 10 queue.enqueue(40) queue.enqueue(50) print(queue.size()) # 4
Implementation Comparison:
  • List (pop(0)): Simple but slow dequeue O(n) - avoid!
  • deque: Fast O(1) operations, dynamic size - BEST for general use
  • Linked List: O(1) operations, no size limit, extra memory for pointers
  • Circular Queue: Fixed size, O(1) operations, efficient space usage

🔄 Types of Queues

1. Simple Queue (Linear Queue)

Standard FIFO queue - enqueue at rear, dequeue from front.

2. Circular Queue

Rear wraps around to start when it reaches end. Efficient space usage.

Circular Queue

Array indices: [0] [1] [2] [3] [4]

When rear reaches index 4, it wraps to index 0 if space available.

3. Priority Queue

Elements dequeued based on priority, not insertion order. Higher priority = dequeued first.

Python - Priority Queue
import heapq class PriorityQueue: """ Priority Queue using heapq (min-heap) Lower number = higher priority """ def __init__(self): self.items = [] def enqueue(self, item, priority): """Add with priority""" heapq.heappush(self.items, (priority, item)) def dequeue(self): """Remove highest priority (lowest number)""" if self.is_empty(): raise IndexError("Queue is empty") return heapq.heappop(self.items)[1] def peek(self): """View highest priority""" if self.is_empty(): raise IndexError("Queue is empty") return self.items[0][1] def is_empty(self): return len(self.items) == 0 def size(self): return len(self.items) # Example pq = PriorityQueue() pq.enqueue("Low priority task", 3) pq.enqueue("High priority task", 1) pq.enqueue("Medium priority task", 2) print(pq.dequeue()) # "High priority task" (priority 1) print(pq.dequeue()) # "Medium priority task" (priority 2) print(pq.dequeue()) # "Low priority task" (priority 3)

4. Deque (Double-Ended Queue)

Can add/remove from both ends. Combination of stack and queue.

Python - Deque Operations
from collections import deque dq = deque() # Add to rear (like queue) dq.append(10) dq.append(20) # Add to front dq.appendleft(5) # Remove from front (like queue) print(dq.popleft()) # 5 # Remove from rear (like stack) print(dq.pop()) # 20 # Result: [10] print(list(dq)) # [10] # Use cases: # - Sliding window problems # - Palindrome checking # - Browser history (back/forward)

Comparison of Queue Types

Type Add Remove Use Case
Simple Queue Rear only Front only General FIFO tasks
Circular Queue Rear (wrap) Front (wrap) Fixed-size buffering
Priority Queue By priority Highest priority Task scheduling, Dijkstra
Deque Both ends Both ends Sliding window, palindrome

🎯 Queue Applications

1. Breadth-First Search (BFS)

BFS explores tree/graph level by level using a queue.

Python - BFS on Tree
from collections import deque class TreeNode: def __init__(self, val): self.val = val self.left = None self.right = None def bfs_tree(root): """ Level-order traversal using queue """ if not root: return [] result = [] queue = deque([root]) while queue: node = queue.popleft() result.append(node.val) if node.left: queue.append(node.left) if node.right: queue.append(node.right) return result # Example tree: # 1 # / \ # 2 3 # / \ # 4 5 root = TreeNode(1) root.left = TreeNode(2) root.right = TreeNode(3) root.left.left = TreeNode(4) root.left.right = TreeNode(5) print(bfs_tree(root)) # [1, 2, 3, 4, 5]

2. Level Order Traversal

Python - Level Order (by level)
def level_order_traversal(root): """ Return nodes grouped by level """ if not root: return [] result = [] queue = deque([root]) while queue: level_size = len(queue) current_level = [] for _ in range(level_size): node = queue.popleft() current_level.append(node.val) if node.left: queue.append(node.left) if node.right: queue.append(node.right) result.append(current_level) return result # Using same tree as above print(level_order_traversal(root)) # Output: [[1], [2, 3], [4, 5]]

3. Shortest Path (BFS on Graph)

Python - BFS for Shortest Path
def shortest_path_bfs(graph, start, end): """ Find shortest path in unweighted graph """ if start == end: return [start] queue = deque([(start, [start])]) visited = {start} while queue: node, path = queue.popleft() for neighbor in graph[node]: if neighbor == end: return path + [neighbor] if neighbor not in visited: visited.add(neighbor) queue.append((neighbor, path + [neighbor])) return None # No path found # Example graph graph = { 'A': ['B', 'C'], 'B': ['A', 'D', 'E'], 'C': ['A', 'F'], 'D': ['B'], 'E': ['B', 'F'], 'F': ['C', 'E'] } print(shortest_path_bfs(graph, 'A', 'F')) # Output: ['A', 'C', 'F']

4. Generate Binary Numbers

Python - Generate Binary Using Queue
def generate_binary_numbers(n): """ Generate binary representations from 1 to n Using queue - clever pattern! """ result = [] queue = deque(['1']) for _ in range(n): binary = queue.popleft() result.append(binary) # Generate next numbers by appending 0 and 1 queue.append(binary + '0') queue.append(binary + '1') return result print(generate_binary_numbers(10)) # Output: ['1', '10', '11', '100', '101', '110', '111', '1000', '1001', '1010']

5. Hot Potato Game (Josephus Problem)

Python - Hot Potato Simulation
def hot_potato(names, num): """ Simulate hot potato game Pass potato num times, person holding it is out """ queue = deque(names) while len(queue) > 1: # Pass the potato for _ in range(num): queue.append(queue.popleft()) # Remove person holding potato eliminated = queue.popleft() print(f"{eliminated} is eliminated!") return queue[0] players = ['Alice', 'Bob', 'Charlie', 'David', 'Eve'] winner = hot_potato(players, 7) print(f"Winner: {winner}")

6. Task Scheduler

Python - Simple Task Scheduler
def schedule_tasks(tasks, cooldown): """ Schedule tasks with cooldown period Same task must wait cooldown cycles """ queue = deque(tasks) time = 0 last_executed = {} while queue: task = queue.popleft() # Check if task can be executed if task in last_executed: wait_time = cooldown - (time - last_executed[task]) if wait_time > 0: # Put task back and add idle time queue.append(task) time += 1 continue # Execute task print(f"Time {time}: Execute {task}") last_executed[task] = time time += 1 return time tasks = ['A', 'A', 'A', 'B', 'B', 'B'] total_time = schedule_tasks(tasks, 2) print(f"Total time: {total_time}")
💡 Queue Applications Pattern:
  • BFS: Process nodes level by level
  • Scheduling: First come, first served
  • Buffering: Store data temporarily in order
  • Shortest Path: Explore nearest nodes first

Problem 1: Implement Queue Using Stacks

Challenge: Implement a queue using two stacks. All operations should maintain FIFO order.

Python - Queue Using Two Stacks
class QueueUsingStacks: """ Implement queue using two stacks Stack 1 for enqueue, Stack 2 for dequeue """ def __init__(self): self.stack1 = [] # For enqueue self.stack2 = [] # For dequeue def enqueue(self, item): """Push to stack1 - O(1)""" self.stack1.append(item) def dequeue(self): """ Pop from stack2 If stack2 empty, transfer from stack1 Amortized O(1) """ if not self.stack2: # Transfer all from stack1 to stack2 while self.stack1: self.stack2.append(self.stack1.pop()) if not self.stack2: raise IndexError("Queue is empty") return self.stack2.pop() def peek(self): """View front without removing""" if not self.stack2: while self.stack1: self.stack2.append(self.stack1.pop()) if not self.stack2: raise IndexError("Queue is empty") return self.stack2[-1] def is_empty(self): return not self.stack1 and not self.stack2 # Test q = QueueUsingStacks() q.enqueue(1) q.enqueue(2) q.enqueue(3) print(q.dequeue()) # 1 (FIFO) print(q.peek()) # 2

def reverse_first_k(queue, k): """ Reverse first k elements of queue Use stack to reverse, then queue for rest """ if k <= 0 or k > len(queue): return queue stack = [] # Push first k to stack for _ in range(k): stack.append(queue.popleft()) # Pop from stack and add back (reversed) while stack: queue.append(stack.pop()) # Move remaining n-k elements to back for _ in range(len(queue) - k): queue.append(queue.popleft()) return queue # Test from collections import deque q = deque([1, 2, 3, 4, 5]) result = reverse_first_k(q, 3) print(list(result)) # [3, 2, 1, 4, 5]

def is_queue_sortable(queue): """ Check if queue can be sorted using a stack Can only dequeue and push/pop from stack """ stack = [] expected = 1 temp_queue = deque(queue) while temp_queue: front = temp_queue.popleft() if front == expected: expected += 1 else: # Check if we can use stack while stack and stack[-1] == expected: stack.pop() expected += 1 stack.append(front) # Check remaining stack while stack: if stack[-1] == expected: stack.pop() expected += 1 else: return False return True # Test print(is_queue_sortable([3, 1, 2])) # True print(is_queue_sortable([3, 2, 1])) # True print(is_queue_sortable([2, 3, 1])) # False

Problem 5: Sliding Window Maximum

Python - Max in Sliding Window Using Deque
def sliding_window_maximum(nums, k): """ Find maximum in each window of size k Use deque to store indices of useful elements """ from collections import deque if not nums or k == 0: return [] dq = deque() # Store indices result = [] for i in range(len(nums)): # Remove elements outside window while dq and dq[0] < i - k + 1: dq.popleft() # Remove smaller elements (not useful) while dq and nums[dq[-1]] < nums[i]: dq.pop() dq.append(i) # Add to result if window complete if i >= k - 1: result.append(nums[dq[0]]) return result # Test nums = [1, 3, -1, -3, 5, 3, 6, 7] k = 3 print(sliding_window_maximum(nums, k)) # Output: [3, 3, 5, 5, 6, 7]

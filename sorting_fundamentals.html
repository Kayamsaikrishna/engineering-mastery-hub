🚀 What is Sorting?

Definition

Sorting is the process of arranging elements in a specific order (ascending or descending). It's one of the most fundamental operations in computer science.

🔑 Critical Insight: The right sorting algorithm can make the difference between O(n²) and O(n log n) - that's 1,000,000 operations vs 20,000 for n=1000!

Why Learn Sorting?

  • Fundamental: Foundation for many other algorithms (search, merge, etc.)
  • Interview Essential: 60%+ of coding interviews involve sorting
  • Real-World: Databases, file systems, e-commerce, social media feeds
  • Performance Critical: Can speed up applications dramatically
  • Algorithm Design: Teaches divide-and-conquer, recursion, optimization
💡 Memory Trick: Sorting = Organizing Books
  • Bubble Sort = Repeatedly swap adjacent books
  • Selection Sort = Find smallest, place at start
  • Insertion Sort = Pick up books one by one, insert in right place
  • Merge Sort = Divide books in half, sort each, merge
  • Quick Sort = Pick a book, partition around it

Key Concepts

Stability

Stable sort: Maintains relative order of equal elements.

Example: [(5,a), (3,b), (5,c)] → After stable sort: [(3,b), (5,a), (5,c)]

Note: (5,a) still comes before (5,c)

In-Place vs Out-of-Place

In-place: Sorts using O(1) extra space (modifies original array)

Out-of-place: Uses O(n) extra space (creates new array)

Adaptive

Adaptive sort: Performance improves if input is partially sorted.

Examples: Insertion Sort, Bubble Sort (with optimization)

📚 Simple Sorting Algorithms

1. Bubble Sort

Bubble Sort repeatedly steps through the list, compares adjacent elements and swaps them if they're in wrong order. Largest elements "bubble" to the end.

Analogy: Like bubbles rising to the surface.

Visual Example: [5, 2, 8, 1, 9]

Pass 1:
5,2 → 2,5 → 2,5,8 → 2,5,1,8 → 2,5,1,8,9
Pass 2:
2,5 → 2,1,5 → 2,1,5,8,9
Pass 3:
2,1 → 1,2,5,8,9
Result:
[1, 2, 5, 8, 9]
Python - Bubble Sort
def bubble_sort(arr): """ Bubble Sort - repeatedly swap adjacent elements """ n = len(arr) # Traverse through all elements for i in range(n): # Last i elements are already sorted for j in range(0, n - i - 1): # Swap if element is greater than next if arr[j] > arr[j + 1]: arr[j], arr[j + 1] = arr[j + 1], arr[j] return arr # Example arr = [64, 34, 25, 12, 22, 11, 90] print(bubble_sort(arr)) # [11, 12, 22, 25, 34, 64, 90]
Python - Optimized Bubble Sort
def bubble_sort_optimized(arr): """ Optimized Bubble Sort - stops if no swaps made Best case: O(n) for already sorted array """ n = len(arr) for i in range(n): swapped = False for j in range(0, n - i - 1): if arr[j] > arr[j + 1]: arr[j], arr[j + 1] = arr[j + 1], arr[j] swapped = True # If no swaps, array is sorted if not swapped: break return arr # Already sorted - only 1 pass! arr = [1, 2, 3, 4, 5] print(bubble_sort_optimized(arr)) # [1, 2, 3, 4, 5]
PSEUDOCODE: Bubble Sort FUNCTION bubbleSort(arr): n = LENGTH(arr) FOR i = 0 TO n - 1: FOR j = 0 TO n - i - 2: IF arr[j] > arr[j + 1]: SWAP arr[j] AND arr[j + 1] END IF END FOR END FOR RETURN arr END FUNCTION Time Complexity: - Best: O(n) - with optimization, already sorted - Average: O(n²) - Worst: O(n²) - reverse sorted Space Complexity: O(1) - in-place Stable: Yes Adaptive: Yes (with optimization)

2. Selection Sort

Selection Sort finds the minimum element and places it at the beginning. Repeat for remaining unsorted portion.

Analogy: Selecting the smallest card from hand repeatedly.

Visual Example: [64, 25, 12, 22, 11]

Step 1:
Find min (11), swap with first → [11, 25, 12, 22, 64]
Step 2:
Find min (12), swap → [11, 12, 25, 22, 64]
Step 3:
Find min (22), swap → [11, 12, 22, 25, 64]
Step 4:
Find min (25), already in place → [11, 12, 22, 25, 64]
Python - Selection Sort
def selection_sort(arr): """ Selection Sort - find minimum and place at start """ n = len(arr) # Traverse unsorted portion for i in range(n): # Find minimum element in unsorted array min_idx = i for j in range(i + 1, n): if arr[j] < arr[min_idx]: min_idx = j # Swap minimum with first unsorted element arr[i], arr[min_idx] = arr[min_idx], arr[i] return arr # Example arr = [64, 25, 12, 22, 11] print(selection_sort(arr)) # [11, 12, 22, 25, 64]
PSEUDOCODE: Selection Sort FUNCTION selectionSort(arr): n = LENGTH(arr) FOR i = 0 TO n - 1: min_idx = i FOR j = i + 1 TO n - 1: IF arr[j] < arr[min_idx]: min_idx = j END IF END FOR SWAP arr[i] AND arr[min_idx] END FOR RETURN arr END FUNCTION Time Complexity: - Best: O(n²) - always makes same comparisons - Average: O(n²) - Worst: O(n²) Space Complexity: O(1) - in-place Stable: No (can be made stable with extra space) Adaptive: No

3. Insertion Sort

Insertion Sort builds sorted array one element at a time by inserting each element into its correct position.

Analogy: Like sorting playing cards in your hand.

Visual Example: [12, 11, 13, 5, 6]

Start:
[12] | 11, 13, 5, 6 (sorted | unsorted)
Insert 11:
[11, 12] | 13, 5, 6
Insert 13:
[11, 12, 13] | 5, 6
Insert 5:
[5, 11, 12, 13] | 6
Insert 6:
[5, 6, 11, 12, 13]
Python - Insertion Sort
def insertion_sort(arr): """ Insertion Sort - insert each element in correct position """ n = len(arr) # Start from second element for i in range(1, n): key = arr[i] j = i - 1 # Move elements greater than key one position ahead while j >= 0 and arr[j] > key: arr[j + 1] = arr[j] j -= 1 # Insert key at correct position arr[j + 1] = key return arr # Example arr = [12, 11, 13, 5, 6] print(insertion_sort(arr)) # [5, 6, 11, 12, 13]
PSEUDOCODE: Insertion Sort FUNCTION insertionSort(arr): n = LENGTH(arr) FOR i = 1 TO n - 1: key = arr[i] j = i - 1 WHILE j >= 0 AND arr[j] > key: arr[j + 1] = arr[j] j = j - 1 END WHILE arr[j + 1] = key END FOR RETURN arr END FUNCTION Time Complexity: - Best: O(n) - already sorted - Average: O(n²) - Worst: O(n²) - reverse sorted Space Complexity: O(1) - in-place Stable: Yes Adaptive: Yes - fast for nearly sorted data
When to Use Simple Sorts:
  • Bubble Sort: Educational purposes, rarely in production
  • Selection Sort: When memory writes are expensive
  • Insertion Sort: Small arrays (< 50), nearly sorted data, online sorting
💡 Remember the Difference:
  • Bubble: Compare adjacent, swap if needed (bubbles up)
  • Selection: Find minimum, swap with first unsorted
  • Insertion: Take element, insert in correct position in sorted part

⚡ Efficient Sorting Algorithms

1. Merge Sort

Merge Sort uses divide-and-conquer: divide array in half, recursively sort each half, then merge.

Analogy: Sorting two decks of cards then merging them.

Visual Example: [38, 27, 43, 3, 9, 82, 10]

Divide:
[38, 27, 43, 3] | [9, 82, 10]
Divide:
[38, 27] [43, 3] | [9, 82] [10]
Divide:
[38] [27] [43] [3] | [9] [82] [10]
Merge:
[27, 38] [3, 43] | [9, 82] [10]
Merge:
[3, 27, 38, 43] | [9, 10, 82]
Final:
[3, 9, 10, 27, 38, 43, 82]
Python - Merge Sort
def merge_sort(arr): """ Merge Sort - divide and conquer """ if len(arr) <= 1: return arr # Divide mid = len(arr) // 2 left = merge_sort(arr[:mid]) right = merge_sort(arr[mid:]) # Conquer (merge) return merge(left, right) def merge(left, right): """ Merge two sorted arrays """ result = [] i = j = 0 # Compare elements from left and right while i < len(left) and j < len(right): if left[i] <= right[j]: result.append(left[i]) i += 1 else: result.append(right[j]) j += 1 # Add remaining elements result.extend(left[i:]) result.extend(right[j:]) return result # Example arr = [38, 27, 43, 3, 9, 82, 10] print(merge_sort(arr)) # [3, 9, 10, 27, 38, 43, 82]
Python - In-Place Merge Sort
def merge_sort_inplace(arr, left=0, right=None): """ In-place merge sort (more memory efficient) """ if right is None: right = len(arr) - 1 if left < right: mid = (left + right) // 2 # Sort first and second halves merge_sort_inplace(arr, left, mid) merge_sort_inplace(arr, mid + 1, right) # Merge the sorted halves merge_inplace(arr, left, mid, right) return arr def merge_inplace(arr, left, mid, right): """ Merge two sorted subarrays arr[left..mid] and arr[mid+1..right] """ # Create temp arrays L = arr[left:mid + 1] R = arr[mid + 1:right + 1] i = j = 0 k = left # Merge back to arr while i < len(L) and j < len(R): if L[i] <= R[j]: arr[k] = L[i] i += 1 else: arr[k] = R[j] j += 1 k += 1 # Copy remaining elements while i < len(L): arr[k] = L[i] i += 1 k += 1 while j < len(R): arr[k] = R[j] j += 1 k += 1 arr = [38, 27, 43, 3, 9, 82, 10] print(merge_sort_inplace(arr)) # [3, 9, 10, 27, 38, 43, 82]
PSEUDOCODE: Merge Sort FUNCTION mergeSort(arr): IF LENGTH(arr) <= 1: RETURN arr END IF mid = LENGTH(arr) / 2 left = mergeSort(arr[0..mid-1]) right = mergeSort(arr[mid..end]) RETURN merge(left, right) END FUNCTION FUNCTION merge(left, right): result = [] i = 0, j = 0 WHILE i < LENGTH(left) AND j < LENGTH(right): IF left[i] <= right[j]: APPEND left[i] to result i = i + 1 ELSE: APPEND right[j] to result j = j + 1 END IF END WHILE APPEND remaining elements from left APPEND remaining elements from right RETURN result END FUNCTION Time Complexity: - Best: O(n log n) - Average: O(n log n) - Worst: O(n log n) - guaranteed! Space Complexity: O(n) - temporary arrays Stable: Yes Divide & Conquer: Yes

2. Quick Sort

Quick Sort picks a pivot element, partitions array around pivot, then recursively sorts partitions.

Analogy: Organizing items: smaller on left, larger on right of a reference item.

Visual Example: [10, 7, 8, 9, 1, 5]

Pivot = 5:
[1] 5 [10, 7, 8, 9] (partition)
Pivot = 9:
[1] 5 [7, 8] 9 [10]
Pivot = 8:
[1] 5 [7] 8 [9, 10]
Result:
[1, 5, 7, 8, 9, 10]
Python - Quick Sort
def quick_sort(arr): """ Quick Sort - partition around pivot """ if len(arr) <= 1: return arr # Choose pivot (last element) pivot = arr[-1] # Partition into smaller, equal, and larger smaller = [x for x in arr[:-1] if x < pivot] equal = [x for x in arr if x == pivot] larger = [x for x in arr[:-1] if x > pivot] # Recursively sort and combine return quick_sort(smaller) + equal + quick_sort(larger) # Example arr = [10, 7, 8, 9, 1, 5] print(quick_sort(arr)) # [1, 5, 7, 8, 9, 10]
Python - In-Place Quick Sort
def quick_sort_inplace(arr, low=0, high=None): """ In-place Quick Sort (more efficient) """ if high is None: high = len(arr) - 1 if low < high: # Partition and get pivot index pi = partition(arr, low, high) # Sort elements before and after partition quick_sort_inplace(arr, low, pi - 1) quick_sort_inplace(arr, pi + 1, high) return arr def partition(arr, low, high): """ Lomuto partition scheme """ # Choose rightmost element as pivot pivot = arr[high] i = low - 1 # Index of smaller element for j in range(low, high): # If current element is smaller than pivot if arr[j] < pivot: i += 1 arr[i], arr[j] = arr[j], arr[i] # Place pivot in correct position arr[i + 1], arr[high] = arr[high], arr[i + 1] return i + 1 arr = [10, 7, 8, 9, 1, 5] print(quick_sort_inplace(arr)) # [1, 5, 7, 8, 9, 10]
Python - Optimized Quick Sort (Random Pivot)
import random def quick_sort_randomized(arr, low=0, high=None): """ Randomized Quick Sort - avoids worst case """ if high is None: high = len(arr) - 1 if low < high: pi = partition_random(arr, low, high) quick_sort_randomized(arr, low, pi - 1) quick_sort_randomized(arr, pi + 1, high) return arr def partition_random(arr, low, high): """ Partition with random pivot """ # Choose random pivot random_idx = random.randint(low, high) arr[random_idx], arr[high] = arr[high], arr[random_idx] return partition(arr, low, high) arr = [10, 7, 8, 9, 1, 5] print(quick_sort_randomized(arr)) # [1, 5, 7, 8, 9, 10]
PSEUDOCODE: Quick Sort FUNCTION quickSort(arr, low, high): IF low < high: pi = partition(arr, low, high) quickSort(arr, low, pi - 1) quickSort(arr, pi + 1, high) END IF END FUNCTION FUNCTION partition(arr, low, high): pivot = arr[high] i = low - 1 FOR j = low TO high - 1: IF arr[j] < pivot: i = i + 1 SWAP arr[i] AND arr[j] END IF END FOR SWAP arr[i + 1] AND arr[high] RETURN i + 1 END FUNCTION Time Complexity: - Best: O(n log n) - balanced partitions - Average: O(n log n) - Worst: O(n²) - already sorted (bad pivot choice) Space Complexity: O(log n) - recursion stack Stable: No (standard implementation) Fastest in practice: Yes (good cache locality)

3. Heap Sort

Heap Sort builds a max heap, then repeatedly extracts the maximum element.

Uses: Binary heap data structure

Python - Heap Sort
def heap_sort(arr): """ Heap Sort - build max heap, extract max repeatedly """ n = len(arr) # Build max heap for i in range(n // 2 - 1, -1, -1): heapify(arr, n, i) # Extract elements from heap one by one for i in range(n - 1, 0, -1): # Move current root to end arr[0], arr[i] = arr[i], arr[0] # Heapify the reduced heap heapify(arr, i, 0) return arr def heapify(arr, n, i): """ Heapify subtree rooted at index i """ largest = i left = 2 * i + 1 right = 2 * i + 2 # Check if left child exists and is greater if left < n and arr[left] > arr[largest]: largest = left # Check if right child exists and is greater if right < n and arr[right] > arr[largest]: largest = right # If largest is not root if largest != i: arr[i], arr[largest] = arr[largest], arr[i] # Recursively heapify the affected subtree heapify(arr, n, largest) # Example arr = [12, 11, 13, 5, 6, 7] print(heap_sort(arr)) # [5, 6, 7, 11, 12, 13]
PSEUDOCODE: Heap Sort FUNCTION heapSort(arr): n = LENGTH(arr) // Build max heap FOR i = n/2 - 1 DOWN TO 0: heapify(arr, n, i) END FOR // Extract elements from heap FOR i = n - 1 DOWN TO 1: SWAP arr[0] AND arr[i] heapify(arr, i, 0) END FOR END FUNCTION FUNCTION heapify(arr, n, i): largest = i left = 2 * i + 1 right = 2 * i + 2 IF left < n AND arr[left] > arr[largest]: largest = left END IF IF right < n AND arr[right] > arr[largest]: largest = right END IF IF largest != i: SWAP arr[i] AND arr[largest] heapify(arr, n, largest) END IF END FUNCTION Time Complexity: O(n log n) - all cases Space Complexity: O(1) - in-place Stable: No
Merge Sort vs Quick Sort:
  • Merge Sort: Guaranteed O(n log n), stable, O(n) space, better for linked lists
  • Quick Sort: Average O(n log n), faster in practice, O(log n) space, in-place
  • Heap Sort: Guaranteed O(n log n), O(1) space, but slower than Quick Sort in practice

🎯 Special Sorting Algorithms

1. Counting Sort

Counting Sort counts occurrences of each value, then reconstructs sorted array.

Best for: Small range of integers (0 to k)

Non-comparison based!

Python - Counting Sort
def counting_sort(arr): """ Counting Sort - count occurrences of each value Works for non-negative integers """ if not arr: return arr # Find range max_val = max(arr) min_val = min(arr) range_size = max_val - min_val + 1 # Count occurrences count = [0] * range_size output = [0] * len(arr) # Store count of each element for num in arr: count[num - min_val] += 1 # Change count[i] to contain actual position for i in range(1, len(count)): count[i] += count[i - 1] # Build output array for i in range(len(arr) - 1, -1, -1): output[count[arr[i] - min_val] - 1] = arr[i] count[arr[i] - min_val] -= 1 return output # Example arr = [4, 2, 2, 8, 3, 3, 1] print(counting_sort(arr)) # [1, 2, 2, 3, 3, 4, 8]
Python - Simple Counting Sort
def counting_sort_simple(arr): """ Simplified counting sort (not stable) """ if not arr: return arr max_val = max(arr) count = [0] * (max_val + 1) # Count each element for num in arr: count[num] += 1 # Reconstruct array result = [] for num in range(len(count)): result.extend([num] * count[num]) return result arr = [4, 2, 2, 8, 3, 3, 1] print(counting_sort_simple(arr)) # [1, 2, 2, 3, 3, 4, 8]
PSEUDOCODE: Counting Sort FUNCTION countingSort(arr): max_val = MAX(arr) count = ARRAY of size (max_val + 1) initialized to 0 // Count occurrences FOR each num IN arr: count[num] = count[num] + 1 END FOR // Reconstruct sorted array result = [] FOR i = 0 TO max_val: APPEND i to result count[i] times END FOR RETURN result END FUNCTION Time Complexity: O(n + k) where k is range Space Complexity: O(k) Stable: Yes (with proper implementation) Best when: k = O(n)

2. Radix Sort

Radix Sort sorts by processing digits from least significant to most significant.

Uses: Counting sort as subroutine

Best for: Integers, strings

Example: [170, 45, 75, 90, 802, 24, 2, 66]

By 1s:
[170, 90, 802, 2, 24, 45, 75, 66]
By 10s:
[802, 2, 24, 45, 66, 170, 75, 90]
By 100s:
[2, 24, 45, 66, 75, 90, 170, 802]
Python - Radix Sort
def radix_sort(arr): """ Radix Sort - sort by each digit using counting sort """ if not arr: return arr # Find maximum number to know number of digits max_num = max(arr) # Do counting sort for every digit exp = 1 while max_num // exp > 0: counting_sort_by_digit(arr, exp) exp *= 10 return arr def counting_sort_by_digit(arr, exp): """ Counting sort based on digit represented by exp """ n = len(arr) output = [0] * n count = [0] * 10 # Store count of occurrences for i in range(n): index = arr[i] // exp count[index % 10] += 1 # Change count[i] to actual position for i in range(1, 10): count[i] += count[i - 1] # Build output array for i in range(n - 1, -1, -1): index = arr[i] // exp output[count[index % 10] - 1] = arr[i] count[index % 10] -= 1 # Copy output to arr for i in range(n): arr[i] = output[i] # Example arr = [170, 45, 75, 90, 802, 24, 2, 66] print(radix_sort(arr)) # [2, 24, 45, 66, 75, 90, 170, 802]
PSEUDOCODE: Radix Sort FUNCTION radixSort(arr): max_num = MAX(arr) exp = 1 WHILE max_num / exp > 0: countingSortByDigit(arr, exp) exp = exp * 10 END WHILE END FUNCTION Time Complexity: O(d * (n + k)) - d = number of digits - k = range of digits (10 for decimal) - Usually O(n) when d is constant Space Complexity: O(n + k) Stable: Yes Non-comparison based: Yes

3. Bucket Sort

Bucket Sort distributes elements into buckets, sorts each bucket, then concatenates.

Best for: Uniformly distributed data

Python - Bucket Sort
def bucket_sort(arr): """ Bucket Sort - distribute into buckets, sort each Works well for uniformly distributed floats [0, 1) """ if len(arr) == 0: return arr # Create buckets bucket_count = len(arr) buckets = [[] for _ in range(bucket_count)] # Distribute elements into buckets for num in arr: index = int(bucket_count * num) # For floats in [0, 1) if index == bucket_count: index -= 1 buckets[index].append(num) # Sort individual buckets (using insertion sort) for bucket in buckets: insertion_sort_bucket(bucket) # Concatenate all buckets result = [] for bucket in buckets: result.extend(bucket) return result def insertion_sort_bucket(arr): """Helper insertion sort for bucket""" for i in range(1, len(arr)): key = arr[i] j = i - 1 while j >= 0 and arr[j] > key: arr[j + 1] = arr[j] j -= 1 arr[j + 1] = key # Example - floats in [0, 1) arr = [0.897, 0.565, 0.656, 0.1234, 0.665, 0.3434] print(bucket_sort(arr)) # [0.1234, 0.3434, 0.565, 0.656, 0.665, 0.897]
Python - Bucket Sort for Integers
def bucket_sort_integers(arr): """ Bucket sort for integers """ if not arr: return arr # Find min and max min_val, max_val = min(arr), max(arr) bucket_range = (max_val - min_val) / len(arr) # Create buckets buckets = [[] for _ in range(len(arr))] # Distribute elements for num in arr: index = int((num - min_val) / bucket_range) if index == len(arr): index -= 1 buckets[index].append(num) # Sort each bucket and concatenate result = [] for bucket in buckets: result.extend(sorted(bucket)) return result arr = [29, 25, 3, 49, 9, 37, 21, 43] print(bucket_sort_integers(arr)) # [3, 9, 21, 25, 29, 37, 43, 49]
When to Use Special Sorts:
  • Counting Sort: Small range of integers (k ≈ n)
  • Radix Sort: Fixed-length integers or strings
  • Bucket Sort: Uniformly distributed floats
  • All three: Can achieve O(n) under right conditions!

Problem 1: Sort Colors (Dutch National Flag)

Given array with 0s, 1s, and 2s. Sort in-place.

Python Solution
def sort_colors(nums): """ Sort array of 0s, 1s, 2s in one pass Three-way partitioning """ low = mid = 0 high = len(nums) - 1 while mid <= high: if nums[mid] == 0: nums[low], nums[mid] = nums[mid], nums[low] low += 1 mid += 1 elif nums[mid] == 1: mid += 1 else: # nums[mid] == 2 nums[mid], nums[high] = nums[high], nums[mid] high -= 1 return nums # Example nums = [2, 0, 2, 1, 1, 0] print(sort_colors(nums)) # [0, 0, 1, 1, 2, 2] # Time: O(n), Space: O(1)
Problem 2: Merge Sorted Arrays

Merge two sorted arrays into one sorted array.

Python Solution
def merge_sorted_arrays(arr1, arr2): """ Merge two sorted arrays """ result = [] i = j = 0 while i < len(arr1) and j < len(arr2): if arr1[i] <= arr2[j]: result.append(arr1[i]) i += 1 else: result.append(arr2[j]) j += 1 # Add remaining elements result.extend(arr1[i:]) result.extend(arr2[j:]) return result arr1 = [1, 3, 5, 7] arr2 = [2, 4, 6, 8] print(merge_sorted_arrays(arr1, arr2)) # [1, 2, 3, 4, 5, 6, 7, 8] # Time: O(n + m), Space: O(n + m)
Problem 3: Kth Largest Element

Find kth largest element using Quick Select (related to Quick Sort).

Python Solution
import random def find_kth_largest(nums, k): """ Find kth largest element using Quick Select Average O(n), Worst O(n²) """ # Convert to kth smallest (from end) return quick_select(nums, 0, len(nums) - 1, len(nums) - k) def quick_select(nums, left, right, k): """ Quick Select algorithm """ if left == right: return nums[left] # Random pivot for better average case pivot_idx = random.randint(left, right) pivot_idx = partition(nums, left, right, pivot_idx) if k == pivot_idx: return nums[k] elif k < pivot_idx: return quick_select(nums, left, pivot_idx - 1, k) else: return quick_select(nums, pivot_idx + 1, right, k) def partition(nums, left, right, pivot_idx): """Partition around pivot""" pivot = nums[pivot_idx] nums[pivot_idx], nums[right] = nums[right], nums[pivot_idx] store_idx = left for i in range(left, right): if nums[i] < pivot: nums[i], nums[store_idx] = nums[store_idx], nums[i] store_idx += 1 nums[store_idx], nums[right] = nums[right], nums[store_idx] return store_idx # Example nums = [3, 2, 1, 5, 6, 4] print(find_kth_largest(nums, 2)) # 5 (2nd largest)

🎯 Key Takeaways

The 10 Commandments of Sorting:
  1. Small data (< 50): Use Insertion Sort
  2. General purpose: Use Quick Sort or Merge Sort
  3. Guaranteed O(n log n): Use Merge Sort or Heap Sort
  4. Stability matters: Use Merge Sort or Insertion Sort
  5. Limited memory: Use Heap Sort or in-place Quick Sort
  6. Nearly sorted: Use Insertion Sort (O(n))
  7. Small range integers: Use Counting Sort
  8. Fixed digits: Use Radix Sort
  9. Uniform distribution: Use Bucket Sort
  10. In production: Use language built-ins (highly optimized)

📚 Quick Reference Card

Question Answer
Fastest average case? Quick Sort O(n log n)
Best worst case? Merge Sort, Heap Sort O(n log n)
Least space? Heap Sort O(1)
Most stable? Merge Sort, Insertion Sort
Best for small data? Insertion Sort O(n²) but low overhead
Best for nearly sorted? Insertion Sort O(n)
Can achieve O(n)? Counting, Radix, Bucket (special cases)
Used in Python? Timsort (Merge + Insertion hybrid)
⚠️ Common Mistakes to Avoid:
  • Using Bubble/Selection Sort for large data
  • Forgetting Quick Sort's O(n²) worst case
  • Not considering stability when needed
  • Using comparison sorts for integer-only data with small range
  • Implementing sorting from scratch in production (use built-ins!)

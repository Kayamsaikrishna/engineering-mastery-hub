🚀 Introduction to Web Development

The Three Pillars of Web Development

HTML (Structure) + CSS (Style) + JavaScript (Behavior) = Web Page

Think of Building a House:

  • HTML = Foundation, walls, rooms (structure)
  • CSS = Paint, decorations, furniture (appearance)
  • JavaScript = Electricity, plumbing, smart devices (functionality)

What Each Technology Does

Technology Purpose Example
HTML Content & Structure Headings, paragraphs, images, links
CSS Styling & Layout Colors, fonts, spacing, positioning
JavaScript Interactivity & Logic Buttons, animations, data processing
💡 Remember: You can't skip any of the three! They work together:
  • HTML without CSS = Ugly but functional
  • HTML without JS = Static, no interaction
  • CSS without HTML = Nothing to style
  • JS without HTML = Nothing to manipulate

Your First Web Page

Complete Web Page Example
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My First Page</title> <style> body { font-family: Arial, sans-serif; background-color: #f0f0f0; padding: 20px; } h1 { color: #333; } button { background-color: #4CAF50; color: white; padding: 10px 20px; border: none; border-radius: 5px; cursor: pointer; } </style> </head> <body> <h1>Hello, World!</h1> <p>This is my first web page.</p> <button onclick="sayHello()">Click Me</button> <script> function sayHello() { alert('Hello from JavaScript!'); } </script> </body> </html>

📄 HTML - HyperText Markup Language

What is HTML?

HTML is the skeleton of every web page. It defines the structure and content using tags.

Basic HTML Structure

HTML - Basic Structure
<!DOCTYPE html> <!-- Declares HTML5 --> <html lang="en"> <!-- Root element --> <head> <!-- Metadata --> <meta charset="UTF-8"> <title>Page Title</title> </head> <body> <!-- Visible content --> <h1>Main Heading</h1> <p>A paragraph</p> </body> </html>

Essential HTML Tags

HTML - Headings & Text
<!-- Headings (h1 largest, h6 smallest) --> <h1>Heading 1</h1> <h2>Heading 2</h2> <h3>Heading 3</h3> <!-- Paragraphs --> <p>This is a paragraph of text.</p> <!-- Text Formatting --> <strong>Bold text</strong> <em>Italic text</em> <u>Underlined text</u> <mark>Highlighted text</mark> <!-- Line breaks --> First line<br> Second line <!-- Horizontal line --> <hr>
HTML - Links & Images
<!-- Links --> <a href="https://google.com">Visit Google</a> <a href="about.html">About Page</a> <a href="#section1">Jump to Section 1</a> <a href="mailto:email@example.com">Email Us</a> <!-- Images --> <img src="image.jpg" alt="Description"> <img src="photo.png" alt="Photo" width="300" height="200">
HTML - Lists
<!-- Unordered List --> <ul> <li>Item 1</li> <li>Item 2</li> <li>Item 3</li> </ul> <!-- Ordered List --> <ol> <li>First step</li> <li>Second step</li> <li>Third step</li> </ol>
HTML - Tables
<table> <thead> <tr> <th>Name</th> <th>Age</th> <th>City</th> </tr> </thead> <tbody> <tr> <td>Alice</td> <td>25</td> <td>NYC</td> </tr> <tr> <td>Bob</td> <td>30</td> <td>LA</td> </tr> </tbody> </table>
HTML - Forms
<form action="/submit" method="POST"> <!-- Text Input --> <label for="name">Name:</label> <input type="text" id="name" name="name" required> <!-- Email Input --> <label for="email">Email:</label> <input type="email" id="email" name="email"> <!-- Password --> <label for="password">Password:</label> <input type="password" id="password" name="password"> <!-- Radio Buttons --> <input type="radio" id="male" name="gender" value="male"> <label for="male">Male</label> <input type="radio" id="female" name="gender" value="female"> <label for="female">Female</label> <!-- Checkbox --> <input type="checkbox" id="subscribe" name="subscribe"> <label for="subscribe">Subscribe to newsletter</label> <!-- Dropdown --> <select name="country"> <option value="us">United States</option> <option value="uk">United Kingdom</option> <option value="in">India</option> </select> <!-- Textarea --> <textarea name="message" rows="4" cols="50"></textarea> <!-- Submit Button --> <button type="submit">Submit</button> </form>
HTML - Semantic Elements
<!-- Modern HTML5 Semantic Tags --> <header> <nav> <a href="#home">Home</a> <a href="#about">About</a> </nav> </header> <main> <article> <h2>Article Title</h2> <p>Article content...</p> </article> <section> <h2>Section Title</h2> <p>Section content...</p> </section> <aside> <p>Sidebar content</p> </aside> </main> <footer> <p>© 2024 My Website</p> </footer>
HTML Best Practices:
  • Use semantic tags (header, nav, main, footer) for better SEO
  • Always include alt text for images
  • Use proper heading hierarchy (h1 → h2 → h3)
  • Close all tags properly
  • Use lowercase for tag names

🎨 CSS - Cascading Style Sheets

What is CSS?

CSS makes web pages beautiful. It controls colors, fonts, spacing, layout, and animations.

Three Ways to Add CSS

CSS - Inline Style
<p style="color: red; font-size: 20px;">Red text</p>
CSS - Internal Style (in <head>)
<head> <style> p { color: blue; font-size: 18px; } </style> </head>
CSS - External Stylesheet (Best Practice)
<!-- In HTML file --> <link rel="stylesheet" href="styles.css"> /* In styles.css file */ p { color: green; font-size: 16px; }

CSS Selectors

CSS - Basic Selectors
/* Element Selector */ p { color: blue; } /* Class Selector */ .my-class { background-color: yellow; } /* ID Selector */ #my-id { font-size: 24px; } /* Multiple Selectors */ h1, h2, h3 { font-family: Arial, sans-serif; } /* Descendant Selector */ div p { margin: 10px; } /* Child Selector */ div > p { padding: 5px; } /* Pseudo-classes */ a:hover { color: red; } button:active { transform: scale(0.95); }

Common CSS Properties

CSS - Text Styling
.text-style { /* Font */ font-family: Arial, sans-serif; font-size: 16px; font-weight: bold; font-style: italic; /* Color */ color: #333; /* Alignment */ text-align: center; /* Decoration */ text-decoration: underline; /* Spacing */ letter-spacing: 2px; line-height: 1.6; }
CSS - Box Model
.box { /* Content size */ width: 300px; height: 200px; /* Padding (inside spacing) */ padding: 20px; padding-top: 10px; padding-right: 15px; padding-bottom: 10px; padding-left: 15px; /* Shorthand: padding: 10px 15px; (vertical horizontal) */ /* Border */ border: 2px solid #333; border-radius: 10px; /* Margin (outside spacing) */ margin: 20px; margin: 10px 20px; /* top/bottom left/right */ margin: 10px 20px 15px 25px; /* top right bottom left */ /* Background */ background-color: #f0f0f0; background-image: url('image.jpg'); background-size: cover; background-position: center; }
CSS - Display & Position
/* Display Property */ .block { display: block; /* Takes full width */ } .inline { display: inline; /* Fits content, no width/height */ } .inline-block { display: inline-block; /* Inline but with width/height */ } .flex { display: flex; /* Flexbox layout */ } .grid { display: grid; /* Grid layout */ } .hidden { display: none; /* Hide element */ } /* Position Property */ .static { position: static; /* Default */ } .relative { position: relative; /* Relative to normal position */ top: 10px; left: 20px; } .absolute { position: absolute; /* Relative to parent */ top: 0; right: 0; } .fixed { position: fixed; /* Relative to viewport */ bottom: 0; right: 0; } .sticky { position: sticky; /* Stick when scrolling */ top: 0; }

Flexbox - Modern Layout

CSS - Flexbox
.container { display: flex; /* Direction */ flex-direction: row; /* default: left to right */ flex-direction: column; /* top to bottom */ /* Alignment */ justify-content: center; /* horizontal alignment */ justify-content: space-between; justify-content: space-around; align-items: center; /* vertical alignment */ align-items: flex-start; align-items: flex-end; /* Wrapping */ flex-wrap: wrap; /* Gap */ gap: 20px; } .item { flex: 1; /* Grow to fill space */ flex-shrink: 0; /* Don't shrink */ }

CSS Grid - 2D Layout

CSS - Grid
.grid-container { display: grid; /* Columns */ grid-template-columns: 200px 200px 200px; grid-template-columns: 1fr 2fr 1fr; /* Fractions */ grid-template-columns: repeat(3, 1fr); /* 3 equal columns */ /* Rows */ grid-template-rows: 100px auto 100px; /* Gap */ gap: 20px; grid-column-gap: 10px; grid-row-gap: 15px; } .grid-item { /* Span multiple columns/rows */ grid-column: 1 / 3; /* From column 1 to 3 */ grid-row: 1 / 2; }

Responsive Design

CSS - Media Queries
/* Mobile First Approach */ .container { width: 100%; padding: 10px; } /* Tablet (768px and up) */ @media (min-width: 768px) { .container { width: 750px; padding: 20px; } } /* Desktop (1024px and up) */ @media (min-width: 1024px) { .container { width: 1000px; padding: 30px; } } /* Large Desktop (1200px and up) */ @media (min-width: 1200px) { .container { width: 1140px; } }

CSS Animations

CSS - Transitions & Animations
/* Transitions (smooth changes) */ .button { background-color: blue; transition: all 0.3s ease; } .button:hover { background-color: red; transform: scale(1.1); } /* Keyframe Animations */ @keyframes slideIn { from { transform: translateX(-100%); opacity: 0; } to { transform: translateX(0); opacity: 1; } } .animated { animation: slideIn 1s ease-in-out; animation-iteration-count: infinite; /* Loop forever */ animation-direction: alternate; /* Back and forth */ }

💡 CSS Tips:
  • Use Flexbox for 1D layouts (row or column)
  • Use Grid for 2D layouts (rows AND columns)
  • Mobile-first: Design for small screens first
  • Use rem/em for responsive font sizes
  • Name classes meaningfully (.btn-primary, not .blue-button)

⚡ JavaScript - Programming Language of the Web

What is JavaScript?

JavaScript makes web pages interactive and dynamic. It's a full programming language that runs in the browser.

Variables & Data Types

JavaScript - Variables
// Three ways to declare variables let name = "Alice"; // Can be changed const age = 25; // Cannot be changed (constant) var city = "NYC"; // Old way (avoid using) // Data Types let string = "Hello"; // String let number = 42; // Number let float = 3.14; // Number (no separate float type) let boolean = true; // Boolean (true/false) let nothing = null; // Null let undefined_var; // Undefined let array = [1, 2, 3]; // Array let object = { // Object name: "Alice", age: 25 }; // Check type console.log(typeof string); // "string"

Operators

JavaScript - Operators
// Arithmetic let sum = 5 + 3; // 8 let diff = 10 - 4; // 6 let product = 4 * 5; // 20 let quotient = 20 / 4; // 5 let remainder = 10 % 3; // 1 let power = 2 ** 3; // 8 // Assignment let x = 10; x += 5; // x = x + 5 = 15 x -= 3; // x = x - 3 = 12 x *= 2; // x = x * 2 = 24 x /= 4; // x = x / 4 = 6 // Comparison 5 == "5" // true (loose equality) 5 === "5" // false (strict equality) 5 != 6 // true 5 !== "5" // true 5 > 3 // true 5 <= 5 // true // Logical true && false // false (AND) true || false // true (OR) !true // false (NOT)

Control Flow

JavaScript - If/Else
let age = 20; if (age >= 18) { console.log("Adult"); } else if (age >= 13) { console.log("Teenager"); } else { console.log("Child"); } // Ternary operator (shorthand) let status = age >= 18 ? "Adult" : "Minor"; // Switch statement let day = "Monday"; switch (day) { case "Monday": console.log("Start of week"); break; case "Friday": console.log("Almost weekend!"); break; default: console.log("Regular day"); }

Loops

JavaScript - Loops
// For loop for (let i = 0; i < 5; i++) { console.log(i); // 0, 1, 2, 3, 4 } // While loop let count = 0; while (count < 5) { console.log(count); count++; } // Do-while (runs at least once) let num = 0; do { console.log(num); num++; } while (num < 5); // For...of (iterate arrays) let fruits = ["apple", "banana", "orange"]; for (let fruit of fruits) { console.log(fruit); } // For...in (iterate object properties) let person = {name: "Alice", age: 25}; for (let key in person) { console.log(key + ": " + person[key]); }

Functions

JavaScript - Functions
// Function declaration function greet(name) { return "Hello, " + name + "!"; } console.log(greet("Alice")); // "Hello, Alice!" // Function expression const add = function(a, b) { return a + b; }; console.log(add(5, 3)); // 8 // Arrow function (modern ES6) const multiply = (a, b) => a * b; console.log(multiply(4, 5)); // 20 // Arrow function with multiple lines const calculate = (x, y) => { let sum = x + y; let product = x * y; return {sum, product}; }; // Default parameters function power(base, exponent = 2) { return base ** exponent; } console.log(power(5)); // 25 (5^2) console.log(power(5, 3)); // 125 (5^3)

Arrays

JavaScript - Array Methods
let numbers = [1, 2, 3, 4, 5]; // Add/Remove elements numbers.push(6); // Add to end: [1,2,3,4,5,6] numbers.pop(); // Remove from end: [1,2,3,4,5] numbers.unshift(0); // Add to start: [0,1,2,3,4,5] numbers.shift(); // Remove from start: [1,2,3,4,5] // Array methods numbers.length; // 5 numbers.includes(3); // true numbers.indexOf(4); // 3 numbers.slice(1, 3); // [2, 3] numbers.splice(2, 1); // Remove 1 element at index 2 // Iteration methods numbers.forEach(num => console.log(num)); // Map (transform each element) let doubled = numbers.map(num => num * 2); // [2, 4, 6, 8, 10] // Filter (keep elements that match condition) let evens = numbers.filter(num => num % 2 === 0); // [2, 4] // Reduce (combine into single value) let sum = numbers.reduce((acc, num) => acc + num, 0); // 15 // Find let found = numbers.find(num => num > 3); // 4 // Some/Every numbers.some(num => num > 3); // true (at least one) numbers.every(num => num > 0); // true (all)

Objects

JavaScript - Objects
// Object literal let person = { name: "Alice", age: 25, city: "NYC", greet: function() { console.log("Hello, I'm " + this.name); } }; // Access properties console.log(person.name); // "Alice" console.log(person["age"]); // 25 // Modify properties person.age = 26; person.email = "alice@example.com"; // Delete property delete person.city; // Object methods Object.keys(person); // ["name", "age", "email", "greet"] Object.values(person); // ["Alice", 26, "alice@example.com", function] Object.entries(person); // Array of [key, value] pairs // Destructuring let {name, age} = person; console.log(name); // "Alice" // Spread operator let newPerson = {...person, country: "USA"}; // Object shorthand let firstName = "Bob"; let lastName = "Smith"; let user = {firstName, lastName}; // {firstName: "Bob", lastName: "Smith"}

ES6+ Modern Features

JavaScript - Modern Features
// Template literals let name = "Alice"; let age = 25; console.log(`Hello, I'm ${name} and I'm ${age} years old.`); // Destructuring let [first, second, ...rest] = [1, 2, 3, 4, 5]; // first = 1, second = 2, rest = [3, 4, 5] // Spread operator let arr1 = [1, 2, 3]; let arr2 = [4, 5, 6]; let combined = [...arr1, ...arr2]; // [1,2,3,4,5,6] // Rest parameters function sum(...numbers) { return numbers.reduce((acc, num) => acc + num, 0); } console.log(sum(1, 2, 3, 4)); // 10 // Optional chaining let user = {profile: {name: "Alice"}}; console.log(user?.profile?.name); // "Alice" console.log(user?.settings?.theme); // undefined (no error) // Nullish coalescing let value = null ?? "default"; // "default" let value2 = 0 ?? "default"; // 0 (only null/undefined trigger default)

Asynchronous JavaScript

JavaScript - Async/Await & Promises
// Promises function fetchData() { return new Promise((resolve, reject) => { setTimeout(() => { resolve("Data loaded!"); }, 2000); }); } fetchData() .then(data => console.log(data)) .catch(error => console.error(error)); // Async/Await (cleaner syntax) async function getData() { try { let response = await fetch('https://api.example.com/data'); let data = await response.json(); console.log(data); } catch (error) { console.error('Error:', error); } } // setTimeout setTimeout(() => { console.log("This runs after 2 seconds"); }, 2000); // setInterval let counter = 0; let interval = setInterval(() => { counter++; console.log(counter); if (counter === 5) clearInterval(interval); }, 1000);
💡 JavaScript Tips:
  • Use const by default, let when value changes
  • Use === instead of == for comparisons
  • Arrow functions (=>) are more concise
  • Array methods (map, filter) are powerful
  • Use async/await for cleaner async code

🎯 DOM Manipulation

What is the DOM?

The Document Object Model (DOM) is how JavaScript interacts with HTML. It represents the page as a tree of objects that you can modify.

Selecting Elements

JavaScript - Selecting Elements
// Get element by ID let element = document.getElementById('myId'); // Get elements by class name (returns HTMLCollection) let elements = document.getElementsByClassName('myClass'); // Get elements by tag name let paragraphs = document.getElementsByTagName('p'); // Query selector (CSS selector) - returns first match let item = document.querySelector('.myClass'); let button = document.querySelector('#submitBtn'); // Query selector all - returns NodeList let allItems = document.querySelectorAll('.item'); // Modern way (most flexible) let header = document.querySelector('header h1');

Modifying Elements

JavaScript - Changing Content & Style
let element = document.querySelector('#myElement'); // Change text content element.textContent = "New text"; // Change HTML content element.innerHTML = "<strong>Bold text</strong>"; // Change attributes element.setAttribute('class', 'active'); element.getAttribute('class'); element.removeAttribute('class'); // Direct attribute access element.id = "newId"; element.className = "myClass"; // Change styles element.style.color = "red"; element.style.fontSize = "20px"; element.style.backgroundColor = "#f0f0f0"; // Add/remove classes element.classList.add('active'); element.classList.remove('hidden'); element.classList.toggle('highlight'); element.classList.contains('active'); // true/false

Creating & Removing Elements

JavaScript - Create/Remove Elements
// Create new element let newDiv = document.createElement('div'); newDiv.textContent = "I'm a new div!"; newDiv.className = "box"; // Add to DOM let container = document.querySelector('#container'); container.appendChild(newDiv); // Add to end container.prepend(newDiv); // Add to beginning container.insertBefore(newDiv, firstChild); // Remove element newDiv.remove(); // Replace element let oldElement = document.querySelector('.old'); let newElement = document.createElement('p'); newElement.textContent = "New element"; oldElement.replaceWith(newElement);

Event Handling

JavaScript - Events
let button = document.querySelector('#myButton'); // Method 1: onclick attribute (not recommended) // <button onclick="handleClick()">Click</button> // Method 2: onclick property button.onclick = function() { console.log("Button clicked!"); }; // Method 3: addEventListener (BEST) button.addEventListener('click', function(event) { console.log("Button clicked!"); console.log(event); // Event object with details }); // Arrow function button.addEventListener('click', (e) => { console.log("Clicked!"); }); // Common events element.addEventListener('click', handleClick); element.addEventListener('dblclick', handleDoubleClick); element.addEventListener('mouseover', handleMouseOver); element.addEventListener('mouseout', handleMouseOut); input.addEventListener('keydown', handleKeyPress); input.addEventListener('keyup', handleKeyRelease); form.addEventListener('submit', handleSubmit); input.addEventListener('change', handleChange); input.addEventListener('input', handleInput); // Every keystroke // Remove event listener button.removeEventListener('click', handleClick); // Event object button.addEventListener('click', (event) => { event.target; // Element that triggered event event.preventDefault(); // Prevent default behavior event.stopPropagation(); // Stop event bubbling });

Form Handling

JavaScript - Forms
let form = document.querySelector('#myForm'); let nameInput = document.querySelector('#name'); form.addEventListener('submit', (e) => { e.preventDefault(); // Prevent page reload // Get form values let name = nameInput.value; let email = document.querySelector('#email').value; // Validate if (name === '') { alert('Name is required!'); return; } // Create form data let formData = new FormData(form); // Process data console.log('Name:', name); console.log('Email:', email); // Reset form form.reset(); }); // Input validation on change nameInput.addEventListener('input', (e) => { let value = e.target.value; if (value.length < 3) { nameInput.style.borderColor = 'red'; } else { nameInput.style.borderColor = 'green'; } });

Local Storage

JavaScript - Local Storage
// Save data (key-value pairs, strings only) localStorage.setItem('username', 'Alice'); localStorage.setItem('age', '25'); // Get data let username = localStorage.getItem('username'); // "Alice" // Save object (convert to JSON) let user = {name: 'Alice', age: 25}; localStorage.setItem('user', JSON.stringify(user)); // Get object (parse JSON) let savedUser = JSON.parse(localStorage.getItem('user')); // Remove item localStorage.removeItem('username'); // Clear all localStorage.clear(); // Check if exists if (localStorage.getItem('username')) { console.log('Username exists!'); }

Fetch API (AJAX)

JavaScript - Fetch API
// GET request fetch('https://api.example.com/users') .then(response => response.json()) .then(data => { console.log(data); }) .catch(error => { console.error('Error:', error); }); // GET with async/await async function getUsers() { try { let response = await fetch('https://api.example.com/users'); let data = await response.json(); console.log(data); } catch (error) { console.error('Error:', error); } } // POST request async function createUser() { try { let response = await fetch('https://api.example.com/users', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name: 'Alice', email: 'alice@example.com' }) }); let data = await response.json(); console.log(data); } catch (error) { console.error('Error:', error); } }

DOM Best Practices:

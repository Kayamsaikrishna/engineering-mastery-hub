🚀 What is Dynamic Programming?

Definition

Dynamic Programming (DP) is an optimization technique that solves complex problems by breaking them down into simpler subproblems and storing their solutions to avoid redundant calculations. It's used when a problem has overlapping subproblems and optimal substructure.

🔑 The Big Idea: "Those who cannot remember the past are condemned to repeat it." - DP remembers solutions to avoid recomputing them!

When to Use Dynamic Programming?

Two Key Properties:

  1. Overlapping Subproblems: Same subproblems are solved multiple times
    • Example: Fibonacci - fib(5) needs fib(3), fib(4) needs fib(3) too!
    • Without DP: Exponential time O(2^n)
    • With DP: Linear time O(n)
  2. Optimal Substructure: Optimal solution contains optimal solutions to subproblems
    • Example: Shortest path contains shortest paths to intermediate nodes
    • Solution to problem can be built from solutions to subproblems

Fibonacci Without DP - Lots of Repeated Work!

                    fib(5)
                  /        \
            fib(4)          fib(3)
            /    \          /    \
        fib(3)  fib(2)  fib(2) fib(1)
        /   \    /  \    /  \
    fib(2) fib(1) ... ... ... ...
    
    fib(3) is calculated TWICE!
    fib(2) is calculated THREE times!
    Lots of wasted computation!
💡 Memory Trick: DP = "Don't Repeat!"
  • Don't compute same thing twice
  • Preserve previous results
  • Trade memory for speed
  • Cache = faster future lookups

Two Approaches to Dynamic Programming

Feature Memoization (Top-Down) Tabulation (Bottom-Up)
Approach Recursive + Cache Iterative + Table
Direction Start from problem, break down Start from base cases, build up
Implementation Easier - modify recursion Harder - need to find order
Space O(n) + recursion stack O(n) - no stack
Speed Slightly slower (function calls) Slightly faster

DP vs Other Techniques

Technique Use When Example
Greedy Local optimum = global optimum Coin change (specific coins), Huffman coding
Divide & Conquer Independent subproblems Merge sort, quick sort, binary search
Dynamic Programming Overlapping subproblems + optimal substructure Fibonacci, knapsack, LCS, shortest path

Common DP Problem Patterns

Recognize These Patterns:

  • 0/1 Knapsack: Include or exclude items
  • Unbounded Knapsack: Unlimited items available
  • Fibonacci Pattern: f(n) = f(n-1) + f(n-2)
  • Grid/Matrix: Paths in grid, edit distance
  • Longest Common Subsequence: String matching
  • Palindrome: Longest palindromic substring
  • Partition: Split array into subsets
  • Game Theory: Optimal play, min-max
⚠️ When NOT to Use DP:
  • No overlapping subproblems (use divide & conquer instead)
  • Simple greedy solution exists
  • Problem requires exploring all possibilities (backtracking)
  • Memory constraints too tight (exponential space needed)

🔝 Memoization (Top-Down DP)

TOP-DOWN

What is Memoization?

Memoization is a top-down approach where you start with the original problem and recursively break it down, caching results as you go. When you encounter a subproblem you've already solved, you return the cached result instead of recomputing.

MEMOIZATION TEMPLATE: memo = {} # Cache for storing results FUNCTION solve(problem_params): # Check if already computed IF problem_params IN memo: RETURN memo[problem_params] END IF # Base case IF base_condition: RETURN base_value END IF # Recursive case result = compute_using_recursive_calls() # Store in cache before returning memo[problem_params] = result RETURN result END FUNCTION

1. Fibonacci - Classic Example

Naive Recursion - O(2^n)
def fib_naive(n): """ Without memoization Time: O(2^n) - EXPONENTIAL! Space: O(n) - recursion stack """ if n <= 1: return n return fib_naive(n - 1) + fib_naive(n - 2) # fib_naive(40) takes forever! print(fib_naive(10)) # 55
With Memoization - O(n)
def fib_memo(n, memo={}): """ With memoization Time: O(n) - each computed once Space: O(n) - cache + stack """ # Check cache if n in memo: return memo[n] # Base case if n <= 1: return n # Compute and cache memo[n] = fib_memo(n-1, memo) + fib_memo(n-2, memo) return memo[n] print(fib_memo(100)) # Instant!
✅ Improvement: From O(2^n) to O(n) - that's going from billions of operations to just 100 for n=100!

2. Climbing Stairs

Problem: You're climbing stairs. You can take 1 or 2 steps at a time. How many distinct ways can you climb n stairs?

Pattern: ways(n) = ways(n-1) + ways(n-2)

Python - Climbing Stairs (Memoization)
def climb_stairs(n, memo={}): """ Count ways to climb n stairs Can take 1 or 2 steps at a time Recurrence: f(n) = f(n-1) + f(n-2) Base cases: f(1) = 1, f(2) = 2 """ if n in memo: return memo[n] if n <= 2: return n memo[n] = climb_stairs(n - 1, memo) + climb_stairs(n - 2, memo) return memo[n] print(climb_stairs(5)) # 8 ways print(climb_stairs(10)) # 89 ways print(climb_stairs(50)) # 20365011074 ways - instant!

3. Minimum Cost Climbing Stairs

Python - Min Cost (Memoization)
def min_cost_climbing(cost, n, memo={}): """ Find minimum cost to reach top cost[i] = cost to step on stair i Can start from step 0 or 1 """ if n in memo: return memo[n] # Base cases if n <= 1: return cost[n] # Min cost = cost of this step + min of previous two memo[n] = cost[n] + min( min_cost_climbing(cost, n - 1, memo), min_cost_climbing(cost, n - 2, memo) ) return memo[n] cost = [10, 15, 20, 25] n = len(cost) # Can start from 0 or 1, reach beyond last step result = min(min_cost_climbing(cost + [0], n, {}), min_cost_climbing(cost + [0], n - 1, {})) print(result) # 30

4. House Robber

Problem: You're a robber. Houses have money. You can't rob adjacent houses (alarm!). What's the maximum money you can rob?

Python - House Robber (Memoization)
def rob(nums, i, memo={}): """ Maximum money you can rob Can't rob adjacent houses Choice at each house: 1. Rob it + rob(i-2) 2. Skip it + rob(i-1) Take maximum """ if i in memo: return memo[i] # Base cases if i < 0: return 0 if i == 0: return nums[0] # Rob this house or skip it rob_current = nums[i] + rob(nums, i - 2, memo) skip_current = rob(nums, i - 1, memo) memo[i] = max(rob_current, skip_current) return memo[i] houses = [2, 7, 9, 3, 1] print(rob(houses, len(houses) - 1, {})) # 12 (rob houses 0, 2, 4)

5. Coin Change (Minimum Coins)

Python - Coin Change (Memoization)
def coin_change(coins, amount, memo={}): """ Minimum coins needed to make amount Unlimited coins of each denomination Return -1 if impossible """ if amount in memo: return memo[amount] # Base cases if amount == 0: return 0 if amount < 0: return float('inf') # Try each coin min_coins = float('inf') for coin in coins: result = coin_change(coins, amount - coin, memo) if result != float('inf'): min_coins = min(min_coins, result + 1) memo[amount] = min_coins return memo[amount] coins = [1, 2, 5] amount = 11 result = coin_change(coins, amount, {}) print(result if result != float('inf') else -1) # 3 (5+5+1)
Memoization Advantages:
  • ✅ Easy to implement - just add caching to recursion
  • ✅ Natural - follows problem structure
  • ✅ Only computes needed subproblems
  • ✅ Good for sparse problems
💡 Memoization Recipe:
  1. Write recursive solution first
  2. Add memo dictionary parameter
  3. Check if result exists in memo
  4. Compute result recursively
  5. Store in memo before returning

📊 Tabulation (Bottom-Up DP)

BOTTOM-UP

What is Tabulation?

Tabulation is a bottom-up approach where you build a table (array/matrix) starting from base cases and iteratively compute solutions to larger subproblems until you reach the original problem. No recursion needed!

TABULATION TEMPLATE: FUNCTION solve(problem_params): # Create DP table dp = CREATE_TABLE(size) # Initialize base cases dp[base_indices] = base_values # Fill table iteratively FOR i FROM start TO end: dp[i] = compute_from_previous(dp[i-1], dp[i-2], ...) END FOR # Return final answer RETURN dp[final_index] END FUNCTION

1. Fibonacci - Bottom-Up

Python - Fibonacci (Tabulation)
def fib_tabulation(n): """ Fibonacci using tabulation Time: O(n) Space: O(n) """ if n <= 1: return n # Create DP table dp = [0] * (n + 1) # Base cases dp[0] = 0 dp[1] = 1 # Fill table from bottom up for i in range(2, n + 1): dp[i] = dp[i - 1] + dp[i - 2] return dp[n] print(fib_tabulation(10)) # 55 print(fib_tabulation(50)) # 12586269025 # Space-optimized version - O(1) space! def fib_optimized(n): """Only need last 2 values""" if n <= 1: return n prev2 = 0 prev1 = 1 for i in range(2, n + 1): current = prev1 + prev2 prev2 = prev1 prev1 = current return prev1 print(fib_optimized(100)) # Same result, O(1) space!

2. Climbing Stairs - Bottom-Up

Python - Climbing Stairs (Tabulation)
def climb_stairs_tab(n): """ Count ways to climb n stairs Time: O(n), Space: O(n) """ if n <= 2: return n dp = [0] * (n + 1) dp[1] = 1 dp[2] = 2 for i in range(3, n + 1): dp[i] = dp[i - 1] + dp[i - 2] return dp[n] print(climb_stairs_tab(5)) # 8 print(climb_stairs_tab(10)) # 89

3. House Robber - Bottom-Up

Python - House Robber (Tabulation)
def rob_tabulation(nums): """ Maximum money you can rob Time: O(n), Space: O(n) """ if not nums: return 0 if len(nums) == 1: return nums[0] n = len(nums) dp = [0] * n # Base cases dp[0] = nums[0] dp[1] = max(nums[0], nums[1]) # Fill table for i in range(2, n): # Rob current + dp[i-2] OR skip current (dp[i-1]) dp[i] = max(nums[i] + dp[i - 2], dp[i - 1]) return dp[n - 1] houses = [2, 7, 9, 3, 1] print(rob_tabulation(houses)) # 12 # Space-optimized O(1) def rob_optimized(nums): """Only need last 2 values""" if not nums: return 0 prev2 = 0 prev1 = 0 for num in nums: current = max(num + prev2, prev1) prev2 = prev1 prev1 = current return prev1 print(rob_optimized(houses)) # 12

4. Coin Change - Bottom-Up

Python - Coin Change (Tabulation)
def coin_change_tab(coins, amount): """ Minimum coins to make amount Time: O(amount × coins), Space: O(amount) """ # dp[i] = min coins to make amount i dp = [float('inf')] * (amount + 1) dp[0] = 0 # 0 coins for amount 0 # For each amount from 1 to target for i in range(1, amount + 1): # Try each coin for coin in coins: if coin <= i: dp[i] = min(dp[i], dp[i - coin] + 1) return dp[amount] if dp[amount] != float('inf') else -1 coins = [1, 2, 5] amount = 11 print(coin_change_tab(coins, amount)) # 3

5. Longest Increasing Subsequence (LIS)

Problem: Find length of longest strictly increasing subsequence in array.

Example: [10, 9, 2, 5, 3, 7, 101, 18] → LIS is [2, 3, 7, 101], length 4

Python - LIS (Tabulation)
def longest_increasing_subsequence(nums): """ Find length of LIS Time: O(n²), Space: O(n) """ if not nums: return 0 n = len(nums) # dp[i] = length of LIS ending at index i dp = [1] * n for i in range(1, n): for j in range(i): if nums[j] < nums[i]: # Can extend LIS ending at j dp[i] = max(dp[i], dp[j] + 1) return max(dp) arr = [10, 9, 2, 5, 3, 7, 101, 18] print(longest_increasing_subsequence(arr)) # 4

6. 0/1 Knapsack Problem

Problem: Given weights and values of items, and a knapsack capacity, maximize value without exceeding capacity. Each item can be taken once (0 or 1).

Python - 0/1 Knapsack (Tabulation)
def knapsack(weights, values, capacity): """ 0/1 Knapsack using tabulation Time: O(n × capacity), Space: O(n × capacity) """ n = len(weights) # dp[i][w] = max value with first i items and capacity w dp = [[0] * (capacity + 1) for _ in range(n + 1)] for i in range(1, n + 1): for w in range(capacity + 1): # Don't take item i-1 dp[i][w] = dp[i - 1][w] # Take item i-1 if it fits if weights[i - 1] <= w: take = values[i - 1] + dp[i - 1][w - weights[i - 1]] dp[i][w] = max(dp[i][w], take) return dp[n][capacity] weights = [1, 3, 4, 5] values = [1, 4, 5, 7] capacity = 7 print(knapsack(weights, values, capacity)) # 9 (items 1 and 3)
Tabulation Advantages:
  • ✅ No recursion overhead - faster
  • ✅ No stack overflow risk
  • ✅ Easy to optimize space
  • ✅ Better for dense problems (all subproblems needed)
💡 Tabulation Recipe:
  1. Identify subproblem structure
  2. Create DP table (1D or 2D)
  3. Initialize base cases
  4. Find recurrence relation
  5. Fill table in correct order
  6. Extract final answer

🎯 Classic DP Problems

1. Longest Common Subsequence (LCS)

Problem: Find length of longest subsequence common to two strings.

Example: "ABCDGH" and "AEDFHR" → LCS is "ADH", length 3

LCS(i, j) = if s1[i] == s2[j]: 1 + LCS(i+1, j+1) else: max(LCS(i+1, j), LCS(i, j+1))
Memoization
def lcs_memo(s1, s2, i, j, memo={}): """LCS using memoization""" if (i, j) in memo: return memo[(i, j)] if i >= len(s1) or j >= len(s2): return 0 if s1[i] == s2[j]: result = 1 + lcs_memo(s1, s2, i+1, j+1, memo) else: result = max( lcs_memo(s1, s2, i+1, j, memo), lcs_memo(s1, s2, i, j+1, memo) ) memo[(i, j)] = result return result print(lcs_memo("ABCDGH", "AEDFHR", 0, 0, {}))
Tabulation
def lcs_tab(s1, s2): """LCS using tabulation""" m, n = len(s1), len(s2) dp = [[0]*(n+1) for _ in range(m+1)] for i in range(1, m + 1): for j in range(1, n + 1): if s1[i-1] == s2[j-1]: dp[i][j] = 1 + dp[i-1][j-1] else: dp[i][j] = max(dp[i-1][j], dp[i][j-1]) return dp[m][n] print(lcs_tab("ABCDGH", "AEDFHR")) # Output: 3

2. Edit Distance (Levenshtein Distance)

Problem: Minimum operations (insert, delete, replace) to convert string1 to string2.

Example: "horse" → "ros" requires 3 operations

Python - Edit Distance
def edit_distance(word1, word2): """ Minimum edit operations Time: O(m × n), Space: O(m × n) """ m, n = len(word1), len(word2) dp = [[0] * (n + 1) for _ in range(m + 1)] # Base cases for i in range(m + 1): dp[i][0] = i # Delete all from word1 for j in range(n + 1): dp[0][j] = j # Insert all to word1 for i in range(1, m + 1): for j in range(1, n + 1): if word1[i - 1] == word2[j - 1]: dp[i][j] = dp[i - 1][j - 1] # No operation else: dp[i][j] = 1 + min( dp[i - 1][j], # Delete dp[i][j - 1], # Insert dp[i - 1][j - 1] # Replace ) return dp[m][n] print(edit_distance("horse", "ros")) # 3 print(edit_distance("intention", "execution")) # 5

3. Unique Paths in Grid

Problem: Robot in m×n grid. Can only move right or down. How many unique paths from top-left to bottom-right?

Python - Unique Paths
def unique_paths(m, n): """ Count unique paths in grid Time: O(m × n), Space: O(m × n) """ # dp[i][j] = paths to reach cell (i, j) dp = [[0] * n for _ in range(m)] # Base case - first row and column for i in range(m): dp[i][0] = 1 for j in range(n): dp[0][j] = 1 # Fill table for i in range(1, m): for j in range(1, n): # Can come from top or left dp[i][j] = dp[i - 1][j] + dp[i][j - 1] return dp[m - 1][n - 1] print(unique_paths(3, 7)) # 28 print(unique_paths(3, 3)) # 6

4. Partition Equal Subset Sum

Problem: Can you partition array into two subsets with equal sum?

Example: [1, 5, 11, 5] → Yes, [1, 5, 5] and [11]

Python - Partition Equal Subset
def can_partition(nums): """ Check if can partition into equal sum subsets Essentially: can we make sum/2 using subset? """ total = sum(nums) # If odd sum, can't partition equally if total % 2 != 0: return False target = total // 2 n = len(nums) # dp[i][j] = can make sum j with first i elements dp = [[False] * (target + 1) for _ in range(n + 1)] # Base case: sum 0 is always possible (empty subset) for i in range(n + 1): dp[i][0] = True for i in range(1, n + 1): for j in range(1, target + 1): # Don't take current number dp[i][j] = dp[i - 1][j] # Take current number if it fits if nums[i - 1] <= j: dp[i][j] = dp[i][j] or dp[i - 1][j - nums[i - 1]] return dp[n][target] print(can_partition([1, 5, 11, 5])) # True print(can_partition([1, 2, 3, 5])) # False

5. Matrix Chain Multiplication

Problem: Given chain of matrices, find optimal parenthesization to minimize multiplications.

Python - Matrix Chain Multiplication
def matrix_chain_order(dims): """ Find minimum multiplications needed dims[i-1] × dims[i] is size of matrix i Example: dims = [10, 20, 30, 40, 30] Matrices: A(10×20), B(20×30), C(30×40), D(40×30) """ n = len(dims) - 1 # Number of matrices # dp[i][j] = min cost to multiply matrices i to j dp = [[0] * n for _ in range(n)] # l is chain length for l in range(2, n + 1): for i in range(n - l + 1): j = i + l - 1 dp[i][j] = float('inf') # Try all possible split points for k in range(i, j): cost = (dp[i][k] + dp[k + 1][j] + dims[i] * dims[k + 1] * dims[j + 1]) dp[i][j] = min(dp[i][j], cost) return dp[0][n - 1] dims = [10, 20, 30, 40, 30] print(matrix_chain_order(dims)) # 30000
💡 Problem-Solving Strategy:
  1. Identify: Does it have overlapping subproblems?
  2. Define: What does dp[i] or dp[i][j] represent?
  3. Recurrence: How to compute dp[i] from smaller subproblems?
  4. Base Cases: What are the simplest cases?
  5. Order: What order to fill the table?
  6. Extract: Where is the final answer?

🚀 Advanced DP Techniques

1. Space Optimization

Many DP problems can reduce space from O(n) or O(n²) to O(1) or O(n) by only keeping necessary previous states.

Python - Space Optimization Example
# Original: O(n) space def fib_normal(n): dp = [0] * (n + 1) dp[0], dp[1] = 0, 1 for i in range(2, n + 1): dp[i] = dp[i-1] + dp[i-2] return dp[n] # Optimized: O(1) space def fib_optimized(n): if n <= 1: return n prev2, prev1 = 0, 1 for i in range(2, n + 1): curr = prev1 + prev2 prev2, prev1 = prev1, curr return prev1 # For 2D DP, often can reduce from O(m×n) to O(n) def lcs_space_optimized(s1, s2): """LCS with O(min(m,n)) space""" if len(s1) < len(s2): s1, s2 = s2, s1 m, n = len(s1), len(s2) prev = [0] * (n + 1) curr = [0] * (n + 1) for i in range(1, m + 1): for j in range(1, n + 1): if s1[i-1] == s2[j-1]: curr[j] = 1 + prev[j-1] else: curr[j] = max(prev[j], curr[j-1]) prev, curr = curr, prev return prev[n]

2. State Compression (Bitmask DP)

Use bitmasks to represent states when dealing with subsets or combinations. Useful for traveling salesman, subset problems.

Python - Bitmask DP Example
def count_subsets_with_sum(nums, target): """ Count subsets with given sum using bitmask For educational purposes - normal DP is better! """ n = len(nums) count = 0 # Iterate through all possible subsets (2^n) for mask in range(1 << n): subset_sum = 0 for i in range(n): # Check if i-th element is in subset if mask & (1 << i): subset_sum += nums[i] if subset_sum == target: count += 1 return count print(count_subsets_with_sum([1, 2, 3, 4], 5)) # 3 subsets

3. DP on Trees

Python - Tree DP Example (House Robber III)
class TreeNode: def __init__(self, val): self.val = val self.left = None self.right = None def rob_tree(root): """ House robber on binary tree Can't rob adjacent nodes (parent-child) """ def helper(node): if not node: return (0, 0) # (rob, not_rob) left = helper(node.left) right = helper(node.right) # If we rob this node, can't rob children rob = node.val + left[1] + right[1] # If we don't rob, take max from children not_rob = max(left) + max(right) return (rob, not_rob) return max(helper(root)) # Build tree and test root = TreeNode(3) root.left = TreeNode(2) root.right = TreeNode(3) root.left.right = TreeNode(3) root.right.right = TreeNode(1) print(rob_tree(root)) # 7

4. Digit DP

Used for counting numbers with certain properties in a range. Common in competitive programming.

Key DP Patterns Summary

Pattern Key Idea Example Problems
Linear DP dp[i] depends on dp[i-1], dp[i-2]... Fibonacci, climbing stairs, house robber
2D Grid DP dp[i][j] from dp[i-1][j] and dp[i][j-1] Unique paths, min path sum
Knapsack Include/exclude items with constraints 0/1 knapsack, subset sum, partition

Interval DP Divide range into subranges Matrix chain, burst balloons

⚠️ Common Mistakes:
  • Wrong base cases
  • Wrong recurrence relation
  • Wrong order of filling table
  • Not handling edge cases (empty input, n=0, etc.)
  • Integer overflow in calculations
  • Forgetting to initialize DP table

🚀 What is a String?

Definition

A string is a sequence of characters. Think of it as an array of characters, where each character has a specific position (index).

🔑 Key Insight: Strings are IMMUTABLE in Python - once created, they cannot be changed! Any modification creates a new string.

Why Learn Strings?

  • Text Processing: Most real-world data is text-based
  • Interview Favorite: 40%+ of coding problems involve strings
  • Pattern Matching: Search engines, DNA sequencing, text editors
  • Data Validation: Email validation, password checks, parsing
💡 Memory Trick: String = "Chain of Letters"
Each letter is a link in the chain, connected in order, but the chain itself is permanent (immutable).

String vs Array: Key Differences

Feature String Array
Mutability Immutable (cannot change) Mutable (can change)
Elements Characters only Any data type
Indexing Zero-based (0 to n-1) Zero-based (0 to n-1)
Concatenation Creates new string Modifies array

2. Accessing Characters

Python - Character Access
s = "Python" # Positive indexing (left to right) print(s[0]) # 'P' (first) print(s[2]) # 't' print(s[5]) # 'n' (last) # Negative indexing (right to left) print(s[-1]) # 'n' (last) print(s[-2]) # 'o' (second last) print(s[-6]) # 'P' (first) # Get length length = len(s) # 6 # Check if index is valid index = 10 if 0 <= index < len(s): print(s[index]) else: print("Index out of bounds!") # Iterate through characters for char in s: print(char) # Iterate with index for i in range(len(s)): print(f"s[{i}] = {s[i]}")
PSEUDOCODE: Access Character FUNCTION accessChar(s, index): IF index >= 0 AND index < LENGTH(s): RETURN s[index] ELSE: RETURN "Index out of bounds" END IF END FUNCTION Time Complexity: O(1) Space Complexity: O(1)
⚠️ Important: Strings are immutable! You cannot do s[0] = 'J'. This will cause an error!

3. String Slicing

Syntax: s[start:end:step]

  • start: Starting index (inclusive)
  • end: Ending index (exclusive)
  • step: Increment (default 1)
Python - String Slicing
s = "Python Programming" # Basic slicing print(s[0:6]) # "Python" print(s[7:18]) # "Programming" # From start print(s[:6]) # "Python" # To end print(s[7:]) # "Programming" # With step print(s[::2]) # "Pto rgamn" (every 2nd char) print(s[1::2]) # "yhnPormig" (every 2nd from index 1) # Reverse string print(s[::-1]) # "gnimmargorP nohtyP" # Extract portion print(s[7:11]) # "Prog" # Negative indices print(s[-11:-1]) # "Programmin" # Copy string copy = s[:] # Creates a copy
💡 Slicing Memory Trick: Remember "up to but not including"
s[0:5] gives you indices 0, 1, 2, 3, 4 (stops BEFORE 5)

4. String Immutability

Python - Understanding Immutability
s = "Hello" # This DOES NOT work (error!) # s[0] = 'J' # TypeError: 'str' object does not support item assignment # To "modify", create a new string s = 'J' + s[1:] # "Jello" print(s) # Another example original = "Python" # Cannot change to "Jython" directly # Method 1: Slicing new_str = 'J' + original[1:] # "Jython" # Method 2: Replace new_str = original.replace('P', 'J') # "Jython" # Method 3: List conversion (for multiple changes) chars = list(original) # ['P', 'y', 't', 'h', 'o', 'n'] chars[0] = 'J' new_str = ''.join(chars) # "Jython"
Why Immutability Matters:
  • Security: Strings can't be changed accidentally
  • Hashability: Can be used as dictionary keys
  • Thread-safe: Multiple threads can use same string
  • Memory: Python can reuse identical strings

Python - String Concatenation
# Method 1: Using + operator s1 = "Hello" s2 = "World" result = s1 + " " + s2 # "Hello World" # Method 2: Using += operator s = "Hello" s += " World" # "Hello World" # Method 3: Using join() - BEST for multiple strings words = ["Hello", "World", "Python"] result = " ".join(words) # "Hello World Python" # Method 4: Using f-strings (Python 3.6+) name = "Alice" age = 25 message = f"My name is {name} and I'm {age}" # Method 5: Using format() message = "My name is {} and I'm {}".format(name, age) # Method 6: Using % operator (old style) message = "My name is %s and I'm %d" % (name, age)

3. String Comparison

Python - Comparing Strings
# Equality s1 = "hello" s2 = "hello" s3 = "Hello" print(s1 == s2) # True print(s1 == s3) # False (case-sensitive) # Case-insensitive comparison print(s1.lower() == s3.lower()) # True # Lexicographic comparison (dictionary order) print("apple" < "banana") # True print("abc" < "abd") # True print("Apple" < "apple") # True (uppercase comes first) # Compare with operators s1 = "abc" s2 = "xyz" print(s1 < s2) # True print(s1 > s2) # False print(s1 != s2) # True # Check if string starts/ends with text = "Hello World" print(text.startswith("Hello")) # True print(text.endswith("World")) # True
PSEUDOCODE: String Comparison FUNCTION compareStrings(s1, s2): IF LENGTH(s1) != LENGTH(s2): RETURN False END IF FOR i = 0 TO LENGTH(s1) - 1: IF s1[i] != s2[i]: RETURN False END IF END FOR RETURN True END FUNCTION Time Complexity: O(n) Space Complexity: O(1)

4. Searching in Strings

Python - String Search
s = "Python Programming Language" # Check if substring exists print("Python" in s) # True print("Java" in s) # False print("python" in s) # False (case-sensitive) # Find index of substring index = s.find("Programming") # 7 print(index) # Find returns -1 if not found index = s.find("Java") # -1 # index() method (raises error if not found) try: index = s.index("Programming") # 7 print(index) except ValueError: print("Substring not found") # Find from right (last occurrence) s = "hello world hello" print(s.rfind("hello")) # 12 (last occurrence) print(s.find("hello")) # 0 (first occurrence) # Count occurrences count = s.count("hello") # 2 print(count)
PSEUDOCODE: Search Substring FUNCTION findSubstring(text, pattern): n = LENGTH(text) m = LENGTH(pattern) FOR i = 0 TO n - m: match = True FOR j = 0 TO m - 1: IF text[i + j] != pattern[j]: match = False BREAK END IF END FOR IF match: RETURN i END IF END FOR RETURN -1 // Not found END FUNCTION Time Complexity: O(n * m) Space Complexity: O(1)

5. String Traversal

6. Reversing Strings

Python - String Reversal
s = "Python" # Method 1: Slicing (easiest) reversed_s = s[::-1] # "nohtyP" # Method 2: Using reversed() function reversed_s = ''.join(reversed(s)) # "nohtyP" # Method 3: Using loop (manual) def reverse_string(s): result = "" for char in s: result = char + result return result # Method 4: Using list and reverse chars = list(s) chars.reverse() reversed_s = ''.join(chars) # Method 5: Two pointer (on list) def reverse_two_pointer(s): chars = list(s) left, right = 0, len(chars) - 1 while left < right: chars[left], chars[right] = chars[right], chars[left] left += 1 right -= 1 return ''.join(chars) print(reverse_two_pointer("Python")) # "nohtyP"
PSEUDOCODE: Reverse String FUNCTION reverseString(s): result = "" FOR i = LENGTH(s) - 1 DOWN TO 0: result = result + s[i] END FOR RETURN result END FUNCTION Time Complexity: O(n) Space Complexity: O(n) - new string created

🎨 Common String Patterns

Pattern 1: Character Frequency Count

Python - Frequency Counter
from collections import Counter s = "hello world" # Method 1: Using dictionary def count_chars(s): freq = {} for char in s: freq[char] = freq.get(char, 0) + 1 return freq print(count_chars(s)) # {'h': 1, 'e': 1, 'l': 3, 'o': 2, ...} # Method 2: Using Counter (easiest) freq = Counter(s) print(freq) # Counter({'l': 3, 'o': 2, ...}) # Most common character print(freq.most_common(1)) # [('l', 3)]
PSEUDOCODE: Character Frequency FUNCTION countFrequency(s): freq = DICTIONARY() FOR each char IN s: IF char IN freq: freq[char] = freq[char] + 1 ELSE: freq[char] = 1 END IF END FOR RETURN freq END FUNCTION Time Complexity: O(n) Space Complexity: O(k) where k = unique characters

Pattern 2: Palindrome Check

Python - Palindrome
# Method 1: Using slicing (simplest) def is_palindrome(s): return s == s[::-1] print(is_palindrome("racecar")) # True print(is_palindrome("hello")) # False # Method 2: Two pointer def is_palindrome_two_pointer(s): left, right = 0, len(s) - 1 while left < right: if s[left] != s[right]: return False left += 1 right -= 1 return True # Method 3: Ignore case and spaces def is_palindrome_clean(s): # Remove spaces and convert to lowercase s = s.replace(" ", "").lower() return s == s[::-1] print(is_palindrome_clean("A man a plan a canal Panama")) # True
PSEUDOCODE: Palindrome Check FUNCTION isPalindrome(s): left = 0 right = LENGTH(s) - 1 WHILE left < right: IF s[left] != s[right]: RETURN False END IF left = left + 1 right = right - 1 END WHILE RETURN True END FUNCTION Time Complexity: O(n) Space Complexity: O(1)

Pattern 3: Anagram Check

Python - Anagram Detection
# Method 1: Sort and compare def is_anagram(s1, s2): return sorted(s1) == sorted(s2) print(is_anagram("listen", "silent")) # True print(is_anagram("hello", "world")) # False # Method 2: Frequency count def is_anagram_freq(s1, s2): if len(s1) != len(s2): return False from collections import Counter return Counter(s1) == Counter(s2) # Method 3: Manual frequency def is_anagram_manual(s1, s2): if len(s1) != len(s2): return False freq = {} # Count characters in s1 for char in s1: freq[char] = freq.get(char, 0) + 1 # Subtract characters from s2 for char in s2: if char not in freq: return False freq[char] -= 1 if freq[char] < 0: return False return True

Pattern 4: Substring Search (Pattern Matching)

Python - Find All Occurrences
def find_all_occurrences(text, pattern): indices = [] start = 0 while True: index = text.find(pattern, start) if index == -1: break indices.append(index) start = index + 1 return indices text = "hello world hello python hello" pattern = "hello" print(find_all_occurrences(text, pattern)) # [0, 12, 25]

Pattern 5: String Reversal Variations

Python - Reverse Words
# Reverse entire string s = "Hello World" print(s[::-1]) # "dlroW olleH" # Reverse word order def reverse_words(s): words = s.split() return ' '.join(reversed(words)) print(reverse_words("Hello World Python")) # "Python World Hello" # Reverse each word individually def reverse_each_word(s): words = s.split() reversed_words = [word[::-1] for word in words] return ' '.join(reversed_words) print(reverse_each_word("Hello World")) # "olleH dlroW"

Pattern 6: Remove Duplicates

Python - Remove Duplicate Characters
# Method 1: Using set (doesn't preserve order) def remove_duplicates_set(s): return ''.join(set(s)) # Method 2: Preserve order (dict) def remove_duplicates_ordered(s): seen = {} result = [] for char in s: if char not in seen: seen[char] = True result.append(char) return ''.join(result) s = "programming" print(remove_duplicates_ordered(s)) # "progamin" # Method 3: Using dict.fromkeys (Python 3.7+) def remove_duplicates_v3(s): return ''.join(dict.fromkeys(s)) print(remove_duplicates_v3("hello")) # "helo"

Pattern 7: First Non-Repeating Character

Python - First Unique Character
def first_non_repeating(s): from collections import Counter # Count frequency freq = Counter(s) # Find first character with frequency 1 for char in s: if freq[char] == 1: return char return None s = "leetcode" print(first_non_repeating(s)) # "l" s = "aabbcc" print(first_non_repeating(s)) # None

Pattern 8: Longest Common Prefix

Python - Common Prefix
def longest_common_prefix(strings): if not strings: return "" # Start with first string prefix = strings[0] for s in strings[1:]: # Reduce prefix until it matches while not s.startswith(prefix): prefix = prefix[:-1] if not prefix: return "" return prefix words = ["flower", "flow", "flight"] print(longest_common_prefix(words)) # "fl" words = ["dog", "racecar", "car"] print(longest_common_prefix(words)) # ""
💡 Pattern Recognition Guide:
  • Frequency: Use dictionary/Counter - O(n)
  • Palindrome: Two pointers or slicing - O(n)
  • Anagram: Sort or frequency count - O(n log n) or O(n)
  • Substring: Use find() in loop - O(n*m)
  • Duplicates: Use set/dict to track seen - O(n)

FUNCTION reverseWords(s): words = SPLIT(s, " ") reversed_words = REVERSE(words) RETURN JOIN(reversed_words, " ") END FUNCTION

def reverse_words(s): words = s.split() return ' '.join(reversed(words)) print(reverse_words("Hello World Python")) # "Python World Hello"
Problem 3: Check if Strings are Rotations
FUNCTION isRotation(s1, s2): IF LENGTH(s1) != LENGTH(s2): RETURN False END IF concatenated = s1 + s1 RETURN s2 IN concatenated END FUNCTION
Python Solution
def is_rotation(s1, s2): if len(s1) != len(s2): return False return s2 in (s1 + s1) print(is_rotation("waterbottle", "erbottlewat")) # True print(is_rotation("hello", "lohel")) # True print(is_rotation("hello", "world")) # False
Problem 4: Remove Spaces
FUNCTION removeSpaces(s): result = "" FOR each char IN s: IF char != " ": result = result + char END IF END FOR RETURN result END FUNCTION
Python Solution
def remove_spaces(s): return s.replace(" ", "") # Or manual def remove_spaces_manual(s): result = "" for char in s: if char != " ": result += char return result # Or using filter def remove_spaces_filter(s): return ''.join(filter(lambda x: x != ' ', s)) print(remove_spaces("Hello World Python")) # "HelloWorldPython"

🎯 Key Takeaways to Remember Forever

The 10 Commandments of Strings:
  1. Immutable: Can't change, only create new strings
  2. Zero-indexed: First character at index 0
  3. Slicing is exclusive: s[1:4] = indices 1, 2, 3
  4. Use join() not +: For concatenating multiple strings
  5. Case matters: "Hello" != "hello"
  6. f-strings are best: For formatting in Python 3.6+
  7. in operator: Fast substring/character checking
  8. Reverse with [::-1]: Simplest way to reverse
  9. Count frequency: Use Counter or dictionary
  10. Validate input: Check length and bounds

📊 Time Complexity Cheat Sheet

Operation Time Complexity Notes

Search (in) O(n) Linear search through string
Concatenation (+) O(n + m) Creates new string

find() O(n * m) n = string length, m = pattern

split() O(n) Creates list of strings
join() O(n) Concatenates list efficiently

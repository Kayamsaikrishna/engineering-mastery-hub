🚀 What is a Linked List?

Definition

A Linked List is a linear data structure where elements (nodes) are stored in memory at non-contiguous locations. Each node contains data and a reference (pointer) to the next node.

Linked List Structure

HEAD →
10
next
→
20
next
→
30
next
→
NULL

Each node points to the next, last node points to NULL

🔑 Critical Insight: Unlike arrays with contiguous memory, linked lists use pointers to connect nodes scattered in memory. This enables dynamic size and efficient insertions/deletions!

Why Learn Linked Lists?

  • Dynamic Size: Grows/shrinks as needed, no fixed capacity
  • Efficient Insertion/Deletion: O(1) at beginning (vs O(n) in arrays)
  • Foundation: Building block for stacks, queues, graphs
  • Interview Essential: Very common in coding interviews
  • Real-World: Browser history, music playlists, undo functionality
  • Memory Management: Allocate memory as needed
💡 Memory Trick: Linked List = Train Cars
  • Each car (node) has cargo (data)
  • Each car connects to next car (pointer)
  • Cars can be anywhere on tracks (non-contiguous memory)
  • Last car has no connection (NULL)
  • Easy to add/remove cars anywhere

Linked List vs Array

Feature Array Linked List
Memory Contiguous Non-contiguous (scattered)
Size Fixed (static) or costly resize Dynamic (grows/shrinks easily)
Access O(1) - Direct index access O(n) - Must traverse from head
Insert at Start O(n) - Shift all elements O(1) - Just update head
Insert at End O(1) - If space available O(n) - Must traverse to end
Delete at Start O(n) - Shift all elements O(1) - Update head
Memory Usage Less (just data) More (data + pointers)
Cache Performance Better (locality) Worse (scattered)
Best For Random access, iteration Frequent insertions/deletions

Types of Linked Lists

  1. Singly Linked List: Each node points to next node only
  2. Doubly Linked List: Each node points to both next and previous
  3. Circular Linked List: Last node points back to first (forms circle)
  4. Circular Doubly Linked List: Combination of circular and doubly

Real-World Applications

Where Linked Lists Are Used:

  • Browser History: Back/forward navigation (doubly linked)
  • Music Player: Next/previous song playlist
  • Undo/Redo: Text editors, image editors
  • Memory Management: Free memory blocks list
  • Hash Tables: Collision handling with chaining
  • Graph Adjacency Lists: Represent graph connections
  • Polynomial Operations: Store and manipulate polynomials

➡️ Singly Linked List

Node Structure

Python - Node Class
class Node: """ Node for singly linked list Contains data and pointer to next node """ def __init__(self, data): self.data = data # Store data self.next = None # Pointer to next node (initially None) # Creating nodes node1 = Node(10) node2 = Node(20) node3 = Node(30) # Linking nodes node1.next = node2 node2.next = node3 node3.next = None # Now we have: 10 -> 20 -> 30 -> NULL

Singly Linked List Implementation

Python - Complete Singly Linked List
class Node: def __init__(self, data): self.data = data self.next = None class SinglyLinkedList: """ Complete singly linked list implementation """ def __init__(self): self.head = None # Start with empty list def is_empty(self): """Check if list is empty""" return self.head is None def insert_at_beginning(self, data): """ Insert at start - O(1) New node becomes head """ new_node = Node(data) new_node.next = self.head self.head = new_node def insert_at_end(self, data): """ Insert at end - O(n) Must traverse to find last node """ new_node = Node(data) # If empty, new node is head if self.is_empty(): self.head = new_node return # Traverse to last node current = self.head while current.next: current = current.next current.next = new_node def insert_at_position(self, data, position): """ Insert at specific position - O(n) Position 0 = beginning """ if position == 0: self.insert_at_beginning(data) return new_node = Node(data) current = self.head # Traverse to position-1 for i in range(position - 1): if current is None: print("Position out of bounds") return current = current.next # Insert node new_node.next = current.next current.next = new_node def delete_from_beginning(self): """ Delete first node - O(1) """ if self.is_empty(): print("List is empty!") return None deleted_data = self.head.data self.head = self.head.next return deleted_data def delete_from_end(self): """ Delete last node - O(n) Need to find second-to-last node """ if self.is_empty(): print("List is empty!") return None # If only one node if self.head.next is None: deleted_data = self.head.data self.head = None return deleted_data # Find second-to-last node current = self.head while current.next.next: current = current.next deleted_data = current.next.data current.next = None return deleted_data def delete_by_value(self, value): """ Delete first node with given value - O(n) """ if self.is_empty(): print("List is empty!") return False # If head contains value if self.head.data == value: self.head = self.head.next return True # Search for node current = self.head while current.next: if current.next.data == value: current.next = current.next.next return True current = current.next print(f"Value {value} not found") return False def search(self, value): """ Search for value - O(n) Returns True if found """ current = self.head while current: if current.data == value: return True current = current.next return False def get_length(self): """ Count nodes - O(n) """ count = 0 current = self.head while current: count += 1 current = current.next return count def display(self): """ Print all elements - O(n) """ if self.is_empty(): print("List is empty") return current = self.head elements = [] while current: elements.append(str(current.data)) current = current.next print(" -> ".join(elements) + " -> NULL") def reverse(self): """ Reverse the linked list - O(n) Uses 3 pointers: prev, current, next """ prev = None current = self.head while current: next_node = current.next # Save next current.next = prev # Reverse link prev = current # Move prev forward current = next_node # Move current forward self.head = prev # Example Usage ll = SinglyLinkedList() ll.insert_at_end(10) ll.insert_at_end(20) ll.insert_at_end(30) ll.insert_at_beginning(5) ll.display() # 5 -> 10 -> 20 -> 30 -> NULL print(f"Length: {ll.get_length()}") # 4 print(f"Search 20: {ll.search(20)}") # True ll.reverse() ll.display() # 30 -> 20 -> 10 -> 5 -> NULL
PSEUDOCODE: Insert at Beginning FUNCTION insertAtBeginning(data): new_node = CREATE_NODE(data) new_node.next = head head = new_node END FUNCTION Time: O(1) Space: O(1)
PSEUDOCODE: Delete from End FUNCTION deleteFromEnd(): IF head == NULL: RETURN "Empty list" END IF IF head.next == NULL: deleted = head.data head = NULL RETURN deleted END IF current = head WHILE current.next.next != NULL: current = current.next END WHILE deleted = current.next.data current.next = NULL RETURN deleted END FUNCTION Time: O(n) Space: O(1)

Time Complexity Summary

Operation Time Complexity Notes
Insert at Beginning O(1) Just update head pointer
Insert at End O(n) Must traverse entire list
Insert at Position O(n) Traverse to position
Delete from Beginning O(1) Just update head
Delete from End O(n) Find second-to-last node
Search O(n) Linear search only
Access by Index O(n) No random access
Get Length O(n) Unless we maintain size variable
⚠️ Common Pitfalls:
  • Losing Head Reference: Always keep track of head!
  • NULL Pointer: Check for NULL before accessing .next
  • Memory Leaks: In languages like C/C++, remember to free memory
  • Infinite Loops: Ensure traversal terminates (check for NULL)
  • Edge Cases: Handle empty list, single node, etc.

1. Traversal

Python - Traverse and Print
def traverse(head): """ Visit each node once - O(n) """ current = head while current is not None: print(current.data, end=" -> ") current = current.next print("NULL")

2. Reverse a Linked List

Reversing Process

Original: 10 → 20 → 30 → NULL
Step 1: NULL ← 10 20 → 30 → NULL
Step 2: NULL ← 10 ← 20 30 → NULL
Step 3: NULL ← 10 ← 20 ← 30
Result: 30 → 20 → 10 → NULL
Python - Iterative Reverse
def reverse_iterative(head): """ Reverse linked list iteratively - O(n) time, O(1) space Use 3 pointers: prev, current, next """ prev = None current = head while current: next_node = current.next # Save next node current.next = prev # Reverse the link prev = current # Move prev forward current = next_node # Move current forward return prev # New head
Python - Recursive Reverse
def reverse_recursive(head): """ Reverse linked list recursively - O(n) time, O(n) space (call stack) """ # Base case if head is None or head.next is None: return head # Reverse rest of list new_head = reverse_recursive(head.next) # Fix current node head.next.next = head head.next = None return new_head

3. Find Middle Element

Python - Two Pointer Technique (Tortoise & Hare)
def find_middle(head): """ Find middle node using slow-fast pointers Slow moves 1 step, fast moves 2 steps When fast reaches end, slow is at middle """ if not head: return None slow = head fast = head while fast and fast.next: slow = slow.next # Move 1 step fast = fast.next.next # Move 2 steps return slow # Middle node # Example: 1->2->3->4->5 # Returns node with value 3

4. Detect Cycle (Floyd's Algorithm)

Problem: Detect if linked list has a cycle (a node's next points back to a previous node)

Python - Detect Cycle
def has_cycle(head): """ Detect cycle using Floyd's algorithm (tortoise & hare) If fast catches slow, there's a cycle """ if not head: return False slow = head fast = head while fast and fast.next: slow = slow.next fast = fast.next.next if slow == fast: # They met - cycle exists! return True return False # Fast reached end - no cycle
Python - Find Cycle Start Point
def find_cycle_start(head): """ Find where cycle begins After detecting cycle, move one pointer to head Move both at same speed - they meet at cycle start """ if not head: return None # Detect cycle slow = fast = head has_cycle = False while fast and fast.next: slow = slow.next fast = fast.next.next if slow == fast: has_cycle = True break if not has_cycle: return None # Find start of cycle slow = head while slow != fast: slow = slow.next fast = fast.next return slow # Start of cycle

5. Remove Duplicates

Python - Remove Duplicates (Sorted List)
def remove_duplicates_sorted(head): """ Remove duplicates from sorted list Compare adjacent nodes """ if not head: return head current = head while current and current.next: if current.data == current.next.data: # Skip duplicate current.next = current.next.next else: current = current.next return head # Example: 1->1->2->3->3->4 # Result: 1->2->3->4
Python - Remove Duplicates (Unsorted List)
def remove_duplicates_unsorted(head): """ Remove duplicates from unsorted list Use hash set to track seen values """ if not head: return head seen = set() seen.add(head.data) current = head while current.next: if current.next.data in seen: # Skip duplicate current.next = current.next.next else: seen.add(current.next.data) current = current.next return head # Example: 1->3->2->1->4->2 # Result: 1->3->2->4

6. Merge Two Sorted Lists

Python - Merge Sorted Lists
def merge_sorted_lists(l1, l2): """ Merge two sorted linked lists into one sorted list Similar to merge step in merge sort """ # Create dummy node to simplify logic dummy = Node(0) current = dummy # Compare and merge while l1 and l2: if l1.data <= l2.data: current.next = l1 l1 = l1.next else: current.next = l2 l2 = l2.next current = current.next # Attach remaining nodes current.next = l1 if l1 else l2 return dummy.next # Skip dummy node # Example: # L1: 1->3->5 # L2: 2->4->6 # Result: 1->2->3->4->5->6

🔄 Types of Linked Lists

1. Doubly Linked List

Doubly Linked List: Each node has pointers to both next and previous nodes. Allows traversal in both directions.

Python - Doubly Linked List Node
class DoublyNode: def __init__(self, data): self.data = data self.next = None # Pointer to next node self.prev = None # Pointer to previous node class DoublyLinkedList: def __init__(self): self.head = None def insert_at_beginning(self, data): """Insert at start - O(1)""" new_node = DoublyNode(data) if self.head: new_node.next = self.head self.head.prev = new_node self.head = new_node def insert_at_end(self, data): """Insert at end - O(n)""" new_node = DoublyNode(data) if not self.head: self.head = new_node return current = self.head while current.next: current = current.next current.next = new_node new_node.prev = current def delete_node(self, node): """ Delete given node - O(1) if node reference known! This is advantage over singly linked list """ if not node: return # Update previous node if node.prev: node.prev.next = node.next else: # Node is head self.head = node.next # Update next node if node.next: node.next.prev = node.prev def display_forward(self): """Print from head to tail""" current = self.head while current: print(current.data, end=" <-> ") current = current.next print("NULL") def display_backward(self): """Print from tail to head""" # Go to last node current = self.head while current and current.next: current = current.next # Traverse backward while current: print(current.data, end=" <-> ") current = current.prev print("NULL") # Example dll = DoublyLinkedList() dll.insert_at_end(10) dll.insert_at_end(20) dll.insert_at_end(30) dll.display_forward() # 10 <-> 20 <-> 30 <-> NULL dll.display_backward() # 30 <-> 20 <-> 10 <-> NULL

2. Circular Linked List

Circular Linked List: Last node points back to first node instead of NULL. Forms a circle - useful for round-robin scheduling.

Python - Circular Linked List
class CircularLinkedList: def __init__(self): self.head = None def insert_at_end(self, data): """Insert at end - O(n)""" new_node = Node(data) if not self.head: self.head = new_node new_node.next = self.head # Point to itself return # Find last node current = self.head while current.next != self.head: current = current.next # Insert and maintain circle current.next = new_node new_node.next = self.head def display(self): """Print circular list (stop after one rotation)""" if not self.head: print("Empty list") return current = self.head while True: print(current.data, end=" -> ") current = current.next if current == self.head: break print("(back to head)") def delete_node(self, value): """Delete node with given value""" if not self.head: return current = self.head prev = None # Find node to delete while True: if current.data == value: # Found node to delete if prev: prev.next = current.next else: # Deleting head # Find last node last = self.head while last.next != self.head: last = last.next if self.head == self.head.next: # Only one node self.head = None else: last.next = self.head.next self.head = self.head.next return prev = current current = current.next if current == self.head: break # Not found # Example cll = CircularLinkedList() cll.insert_at_end(10) cll.insert_at_end(20) cll.insert_at_end(30) cll.display() # 10 -> 20 -> 30 -> (back to head)

1. Remove Nth Node from End

Python - Remove Nth from End (One Pass)
def remove_nth_from_end(head, n): """ Remove nth node from end using two pointers Maintain gap of n between pointers """ dummy = Node(0) dummy.next = head first = dummy second = dummy # Move first pointer n+1 steps ahead for i in range(n + 1): first = first.next # Move both pointers until first reaches end while first: first = first.next second = second.next # Remove node second.next = second.next.next return dummy.next # Example: Remove 2nd from end in 1->2->3->4->5 # Result: 1->2->3->5

2. Add Two Numbers (Lists Represent Numbers)

Python - Add Two Numbers
def add_two_numbers(l1, l2): """ Add two numbers represented as linked lists Lists store digits in reverse order Example: 342 + 465 = 807 L1: 2->4->3 (represents 342) L2: 5->6->4 (represents 465) Result: 7->0->8 (represents 807) """ dummy = Node(0) current = dummy carry = 0 while l1 or l2 or carry: # Get values (0 if node is None) val1 = l1.data if l1 else 0 val2 = l2.data if l2 else 0 # Calculate sum and carry total = val1 + val2 + carry carry = total // 10 digit = total % 10 # Create new node current.next = Node(digit) current = current.next # Move to next nodes l1 = l1.next if l1 else None l2 = l2.next if l2 else None return dummy.next

def get_intersection_node(headA, headB): """ Find node where two lists intersect Use two pointers - when they meet, that's intersection """ if not headA or not headB: return None # Get lengths lenA = get_length(headA) lenB = get_length(headB) # Align start points while lenA > lenB: headA = headA.next lenA -= 1 while lenB > lenA: headB = headB.next lenB -= 1 # Find intersection while headA != headB: headA = headA.next headB = headB.next return headA # Intersection node (or None) def get_length(head): count = 0 while head: count += 1 head = head.next return count

4. Flatten Multilevel List

Python - Flatten List with Child Pointers
def flatten(head): """ Flatten multilevel doubly linked list Nodes may have child pointer to another list """ if not head: return head current = head while current: # If no child, move to next if not current.child: current = current.next continue # Process child list child = current.child # Find tail of child list tail = child while tail.next: tail = tail.next # Connect child list between current and next tail.next = current.next if current.next: current.next.prev = tail current.next = child child.prev = current current.child = None current = current.next return head

5. Clone List with Random Pointer

Python - Deep Copy with Random Pointers
class NodeWithRandom: def __init__(self, data): self.data = data self.next = None self.random = None # Can point to any node def copy_random_list(head): """ Create deep copy of list with random pointers Use hash map to track original->copy mapping """ if not head: return None # Map original nodes to copies node_map = {} # First pass: create all nodes current = head while current: node_map[current] = NodeWithRandom(current.data) current = current.next # Second pass: set next and random pointers current = head while current: if current.next: node_map[current].next = node_map[current.next] if current.random: node_map[current].random = node_map[current.random] current = current.next return node_map[head]

6. Sort Linked List

Python - Merge Sort on Linked List
def sort_list(head): """ Sort linked list using merge sort - O(n log n) Better than insertion sort O(n²) for large lists """ if not head or not head.next: return head # Split list in half mid = get_middle(head) right_head = mid.next mid.next = None # Recursively sort both halves left = sort_list(head) right = sort_list(right_head) # Merge sorted halves return merge_sorted(left, right) def get_middle(head): """Find middle using slow-fast pointers""" slow = head fast = head while fast.next and fast.next.next: slow = slow.next fast = fast.next.next return slow def merge_sorted(l1, l2): """Merge two sorted lists""" dummy = Node(0) current = dummy while l1 and l2: if l1.data <= l2.data: current.next = l1 l1 = l1.next else: current.next = l2 l2 = l2.next current = current.next current.next = l1 if l1 else l2 return dummy.next
💡 Problem-Solving Patterns:
  • Two Pointers: Middle, cycle, nth from end
  • Dummy Node: Simplifies edge cases (merge, reverse)
  • Hash Map: Cycle detection, random pointer copy
  • Recursion: Reverse, merge sort, flatten
  • Runner Technique: Fast-slow pointers

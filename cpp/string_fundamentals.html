🚀 What is a String in C++?

Definition

In C++, a std::string is a class that manages a character array internally. Unlike C-style strings (char arrays), std::string is dynamic, safe, and powerful.

It handles memory management automatically, growing and shrinking as needed.

🔑 Key Insight: C++ Strings are MUTABLE. You can modify characters in place: s[0] = 'X' is valid!

Why Use std::string over char[]?

Feature std::string (C++) char[] (C-Style)
Safety Safe (bounds check with .at()) Unsafe (buffer overflow risk)
Memory Automatic management Manual management
Operations Easy (+, ==, find) Hard (strcat, strcmp, strstr)
Mutability Mutable Mutable
💡 Tip: Always prefer std::string in C++ unless you are interacting with legacy C libraries.

📚 String Basics in C++

1. Creating Strings

C++ - String Creation
#include <string> #include <iostream> using namespace std; // Method 1: String Literal string s1 = "Hello"; // Method 2: Constructor string s2("World"); // Method 3: Repeat Constructor string s3(5, 'a'); // "aaaaa" // Method 4: From part of another string string s4(s1, 0, 3); // "Hel" (Starts at 0, length 3) // Method 5: Empty String string s5; // Check identity string a = "Test"; string b = "Test"; // In C++, == checks content, not memory address! cout << (a == b); // 1 (true)
PSEUDOCODE: String Creation DECLARE string s SET s = "Hello World" SET length = s.length()

2. Accessing Characters

C++ - Character Access
string s = "C++"; // Method 1: Array Indexing (Unchecked - Fast) char first = s[0]; // 'C' char last = s[s.size() - 1]; // '+' // Method 2: at() function (Checked - Safer) try { char c = s.at(10); // Throws out_of_range exception } catch (out_of_range& e) { cout << "Error: " << e.what(); } // Get length int len = s.length(); // or s.size() // Iterate through characters // Method 1: Range-based Loop (Best) for (char c : s) { cout << c << " "; } // Method 2: Standard For Loop for (int i = 0; i < s.length(); i++) { cout << s[i]; }
⚠️ Safety Tip: s[i] is faster but doesn't check bounds. s.at(i) is safer but slightly slower. Use s.at() during debugging or with uncertain inputs.

3. String Slicing (Substring)

Syntax: s.substr(pos, len)

  • pos: Starting index (default 0)
  • len: Length of substring (NOT end index!)
C++ - Substrings
string s = "C++ Programming"; // Basic substring string sub1 = s.substr(0, 3); // "C++" (Start 0, Length 3) string sub2 = s.substr(4, 11); // "Programming" (Start 4, Length 11) // From start index to end string sub3 = s.substr(4); // "Programming" // CAUTION: Python vs C++ Difference // Python: s[0:3] (Start 0, End 3) // C++: s.substr(0, 3) (Start 0, Length 3) // Copy string string copy = s;
💡 C++ vs Python: Remember "Length" not "End Index"!

4. String Mutability

C++ - Mutability
string s = "Hello"; // C++ Strings are MUTABLE! s[0] = 'J'; cout << s; // "Jello" // Modify range s.replace(0, 1, "Ye"); // "Yello" (Replaces 1 char at 0 with "Ye") // Append s += " World"; // "Yello World" // Insert s.insert(5, ","); // "Yello, World" // Erase s.erase(5, 1); // "Yello World" (Remove 1 char at index 5)
Why Mutability Matters:
  • Performance: Modify in place without creating new copies.
  • Flexibility: Modify individual characters easily.

⚙️ Core String Operations in C++

1. Concatenation (Joining Strings)

C++ - String Concatenation
#include <string> string s1 = "Hello"; string s2 = "World"; // Method 1: + operator string result = s1 + " " + s2; // "Hello World" // Method 2: += operator (Appends) string s = "Hello"; s += " World"; // Method 3: append() s.append("!"); // Note: + operator creates a new string (slower). // += and append() modify in place (faster).
PSEUDOCODE: String Concatenation FUNCTION concatenate(s1, s2): RETURN s1 + s2 END FUNCTION Time Complexity: O(n + m) (for +) Space Complexity: O(n + m)

2. String Repetition

C++ - String Repetition
// Method 1: Constructor (Chars only) string s(5, 'a'); // "aaaaa" // Method 2: Loop (Strings) string pattern = "Ha"; string repeated; for(int i = 0; i < 3; i++) { repeated += pattern; } // repeated = "HaHaHa"

3. String Comparison

C++ - Comparing Strings
string s1 = "hello"; string s2 = "Hello"; // 1. Equality (Checks Content!) if (s1 == "hello") cout << "Equal"; // true // 2. Inequality if (s1 != s2) cout << "Not Equal"; // true // 3. Relational (<, >) if (s1 > s2) cout << "s1 is larger"; // true (lowercase > uppercase in ASCII) // 4. compare() method (Returns 0, <0, >0) if (s1.compare(s2) != 0) cout << "Different";

4. Searching in Strings

C++ - String Search
string s = "C++ Programming"; // Find substring - Returns index (0-based) size_t found = s.find("Programming"); // 4 if (found != string::npos) { cout << "Found at: " << found; } else { cout << "Not found"; } // Find character size_t charPos = s.find('P'); // 4 // Reverse Find (Last occurrence) size_t last = s.rfind('m'); // Find First Of (Finds any char from set) size_t any = s.find_first_of("aeiou"); // Find first vowel

5. String Traversal

C++ - Traversing Strings
string s = "C++"; // Method 1: Range-based For Loop (C++11) - CLEANEST for (char c : s) { cout << c << " "; } // Method 2: Standard Index Loop for (int i = 0; i < s.length(); i++) { cout << s[i]; } // Method 3: Iterators (STL Style) for (string::iterator it = s.begin(); it != s.end(); ++it) { cout << *it; }

6. Reversing Strings

C++ - String Reversal
#include <algorithm> // Required for reverse string s = "C++"; // Method 1: In-place Reversal (Modifies s) reverse(s.begin(), s.end()); // s is now "++C" // Method 2: Create Reversed Copy string reversed(s.rbegin(), s.rend()); // Manual Swap int left = 0, right = s.length() - 1; while(left < right) { swap(s[left], s[right]); left++; right--; }

🛠️ Essential String Methods in C++

1. Case Conversion

C++ - Case Methods
#include <cctype> #include <algorithm> string s = "Hello World"; // Convert to Uppercase (In-place) for (char &c : s) c = toupper(c); // Convert to Lowercase (Using transform) transform(s.begin(), s.end(), s.begin(), ::tolower);

2. Whitespace Handling (Trim)

C++ - Manual Trim
// C++ has no built-in trim! string s = " Hello "; // Remove leading spaces s.erase(0, s.find_first_not_of(' ')); // Remove trailing spaces s.erase(s.find_last_not_of(' ') + 1);

C++ - String/Number Conversion

4. Replacement

C++ - Replace
string s = "Hello World"; // Replace part of string (pos, len, new_str) s.replace(6, 5, "C++"); // "Hello C++" (Replaces "World") // Replace all occurrences (Custom function) void replaceAll(string& str, const string& from, const string& to) { size_t start_pos = 0; while((start_pos = str.find(from, start_pos)) != string::npos) { str.replace(start_pos, from.length(), to); start_pos += to.length(); } }

🎨 Common String Patterns

Pattern 1: Character Frequency Count

C++ - Frequency Counter
#include <map> string s = "hello world"; map<char, int> freq; for (char c : s) { freq[c]++; } // Print for (auto const& [key, val] : freq) { cout << key << ": " << val << endl; }
PSEUDOCODE: Character Frequency Time Complexity: O(n log k) (Map) or O(n) (Unordered Map) Space Complexity: O(k)

Pattern 2: Palindrome Check

C++ - Palindrome
bool isPalindrome(string s) { string rev = s; reverse(rev.begin(), rev.end()); return s == rev; } // Two Pointer (Efficient) bool isPalindromeOpt(string s) { int l = 0, r = s.length() - 1; while (l < r) { if (s[l] != s[r]) return false; l++; r--; } return true; }

Pattern 3: Anagram Check

C++ - Anagram Detection
#include <algorithm> bool isAnagram(string s1, string s2) { sort(s1.begin(), s1.end()); sort(s2.begin(), s2.end()); return s1 == s2; } // Frequency Array (O(n)) bool isAnagramFreq(string s1, string s2) { if (s1.length() != s2.length()) return false; int count[26] = {0}; for (char c : s1) count[c - 'a']++; for (char c : s2) count[c - 'a']--; for (int i : count) if (i != 0) return false; return true; }

Pattern 4: Substring Search

C++ - Find All Occurrences
string text = "banana"; string pat = "an"; size_t pos = text.find(pat); while (pos != string::npos) { cout << "Found at: " << pos << endl; pos = text.find(pat, pos + 1); }

🏋️ Practice Problems

Problem 1: Count Vowels
C++ Solution
int countVowels(string s) { string vowels = "aeiouAEIOU"; int count = 0; for (char c : s) { if (vowels.find(c) != string::npos) { count++; } } return count; }
Problem 2: Reverse Words in Sentence
C++ Solution
#include <sstream> #include <vector> string reverseWords(string s) { stringstream ss(s); string word, result; vector<string> words; while (ss >> word) words.push_back(word); for (int i = words.size() - 1; i >= 0; i--) { result += words[i]; if (i > 0) result += " "; } return result; }
Problem 3: Check if Strings are Rotations
C++ Solution
bool isRotation(string s1, string s2) { if (s1.length() != s2.length()) return false; return (s1 + s1).find(s2) != string::npos; }
Problem 4: Remove Spaces
C++ Solution
string removeSpaces(string s) { // Erase-Remove Idiom s.erase(remove(s.begin(), s.end(), ' '), s.end()); return s; }

🎯 Key Takeaways to Remember Forever

The 10 Commandments of Strings:
  1. Immutable: Can't change, only create new strings
  2. Zero-indexed: First character at index 0
  3. Slicing is exclusive: s[1:4] = indices 1, 2, 3
  4. Use join() not +: For concatenating multiple strings
  5. Case matters: "Hello" != "hello"
  6. f-strings are best: For formatting in Python 3.6+
  7. in operator: Fast substring/character checking
  8. Reverse with [::-1]: Simplest way to reverse
  9. Count frequency: Use Counter or dictionary
  10. Validate input: Check length and bounds

📊 Time Complexity Cheat Sheet

Operation Time Complexity Notes
Access s[i] O(1) Direct index access
Search (in) O(n) Linear search through string
Concatenation (+) O(n + m) Creates new string
Slicing s[i:j] O(j - i) Copies substring
find() O(n * m) n = string length, m = pattern
replace() O(n) Creates new string
split() O(n) Creates list of strings
join() O(n) Concatenates list efficiently

🚀 Why Bit Manipulation in C++?

Definition

Bit manipulation is the act of algorithmically manipulating bits or other pieces of data shorter than a word. C++ gives you raw access to hardware-level operations.

In C++, you have both signed and unsigned types. Understanding std::bitset makes visualization easy.

2. Visualizing Binary in C++

C++ - std::bitset
#include <iostream> #include <bitset> int n = 5; std::cout << std::bitset<8>(n) << std::endl; // 00000101 int neg = -5; std::cout << std::bitset<8>(neg) << std::endl; // 11111011 (Two's Complement)

3. Right Shift: Arithmetic vs Logical

Signed Integers: >> is implementation-defined (usually Arithmetic shift, preserves sign).

Unsigned Integers: >> is always Logical shift (fills with 0).

int a = -10; unsigned int b = 10; // a >> 1 preserves negative sign // b >> 1 fills with 0

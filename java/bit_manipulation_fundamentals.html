🚀 Why Bit Manipulation in Java?

Definition

Bit manipulation involves working directly with the binary representations of integers. In Java, all integers are SIGNED (Two's Complement). There are no unsigned primitives (until Java 8 utility methods), which makes understanding the sign bit critical.

🔑 Java Specifics:
  • int is always 32-bit signed.
  • long is always 64-bit signed.
  • Java has a special Unsigned Right Shift (>>>) operator.

📚 Java Bitwise Operators

OperatorNameDescription
&AND1 if both bits are 1
|OR1 if either bit is 1
^XOR1 if bits are different
~NOTFlip all bits (One's Complement)
<<Left ShiftMultiply by 2^k
>>Signed Right ShiftDivide by 2^k (Preserves Sign)
>>>Unsigned Right ShiftShift right, fill with 0 (Ignored Sign)

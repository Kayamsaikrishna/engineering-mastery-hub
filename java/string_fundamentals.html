🚀 What is a String?

Definition

In Java, a String is an object that represents a sequence of characters. Internally, it is backed by a char[] (or byte[] in newer versions).

a

🔑 Key Insight: Strings in Java are IMMUTABLE. Once created, they cannot be changed. Modification creates a new object in the String Pool.

Why Learn Strings?

  • Text Processing: Most real-world data is text-based
  • Interview Favorite: 40%+ of coding problems involve strings
  • Pattern Matching: Search engines, DNA sequencing, text editors
  • Data Validation: Email validation, password checks, parsing
💡 Memory Trick: String = "Chain of Letters"
Each letter is a link in the chain, connected in order, but the chain itself is permanent (immutable).

📚 String Basics in Java

1. Creating Strings

Java - String Creation
// Method 1: String Literal (Stored in String Pool) String s1 = "Hello"; // Method 2: new Keyword (Stored in Heap) String s2 = new String("World"); // Method 3: From char array char[] arr = {'J', 'a', 'v', 'a'}; String s3 = new String(arr); // Method 4: StringBuilder (Mutable) StringBuilder sb = new StringBuilder("Mutable"); // Method 5: Empty String String s4 = ""; // Check identity String a = "Test"; String b = "Test"; System.out.println(a == b); // true (Same reference in Pool) String c = new String("Test"); System.out.println(a == c); // false (Different objects)
PSEUDOCODE: String Creation DECLARE String s SET s = "Hello World" SET length = s.length()

2. Accessing Characters

Java - Character Access
String s = "Java"; // Get character at index char first = s.charAt(0); // 'J' char last = s.charAt(s.length() - 1); // 'a' // Get length int len = s.length(); // 4 // Iterate through characters // Method 1: Standard For Loop for (int i = 0; i < s.length(); i++) { System.out.println("Char at " + i + ": " + s.charAt(i)); } // Method 2: Enhanced For Loop (toCharArray) for (char c : s.toCharArray()) { System.out.println(c); }
⚠️ Important: Java strings do NOT support array indexing like `s[0]`. You MUST use `s.charAt(0)`.

3. String Slicing (Substring)

Syntax: s.substring(start, end)

  • start: Starting index (inclusive)
  • end: Ending index (exclusive)
  • Note: Java does not have built-in step slicing like Python.
Java - Substrings
String s = "Java Programming"; // Basic substring String sub1 = s.substring(0, 4); // "Java" String sub2 = s.substring(5, 16); // "Programming" // From start index to end String sub3 = s.substring(5); // "Programming" // Extract portion String code = s.substring(0, 1); // "J" // Reverse string (No slicing, needs StringBuilder) String reversed = new StringBuilder(s).reverse().toString(); // Copy string String copy = new String(s);
💡 Substring Trick: endIndex - beginIndex always equals the length of the substring.

4. String Immutability

Java - Understanding Immutability
String s = "Hello"; // This DOES NOT change 's', it creates a new string s.concat(" World"); System.out.println(s); // "Hello" (Original unchanged) // Must reassign to change reference s = s.concat(" World"); System.out.println(s); // "Hello World" // Using StringBuilder for mutability StringBuilder sb = new StringBuilder("Hello"); sb.append(" World"); // Modifies object in place sb.setCharAt(0, 'J'); // "Jello World" System.out.println(sb.toString());
Why Immutability Matters:
  • String Pool: Saves memory by reusing literals.
  • Security: Safe for sensitive data (DB connections, passwords).
  • Thread Safety: No synchronization needed for read-only strings.

Java - String Concatenation

Java - Trim & Strip

🎨 Common String Patterns

Pattern 1: Character Frequency Count

Java - Frequency Counter
import java.util.HashMap; import java.util.Map; String s = "hello world"; Map freq = new HashMap<>(); for (char c : s.toCharArray()) { freq.put(c, freq.getOrDefault(c, 0) + 1); } // Print frequencies for (Map.Entry entry : freq.entrySet()) { System.out.println(entry.getKey() + ": " + entry.getValue()); }
PSEUDOCODE: Character Frequency FUNCTION countFrequency(s): freq = Dictionary/Map IF s is NULL return null FOR each char c IN s: IF freq contains c: freq[c] = freq[c] + 1 ELSE: freq[c] = 1 RETURN freq END FUNCTION Time Complexity: O(n) Space Complexity: O(k)

Pattern 2: Palindrome Check

Java - Palindrome
String s = "racecar"; // Method 1: Using StringBuilder (Easiest) boolean isPalindrome = new StringBuilder(s).reverse().toString().equals(s); // Method 2: Two Pointer (Efficient) boolean check(String str) { int left = 0, right = str.length() - 1; while (left < right) { if (str.charAt(left) != str.charAt(right)) return false; left++; right--; } return true; }
PSEUDOCODE: Palindrome Check FUNCTION isPalindrome(s): left = 0 right = LENGTH(s) - 1 WHILE left < right: IF s[left] != s[right]: RETURN False left = left + 1 right = right - 1 END WHILE RETURN True END FUNCTION Time Complexity: O(n) Space Complexity: O(1)

Pattern 3: Anagram Check

Java - Anagram Detection
import java.util.Arrays; String s1 = "listen"; String s2 = "silent"; // Method 1: Sorting (O(n log n)) char[] c1 = s1.toCharArray(); char[] c2 = s2.toCharArray(); Arrays.sort(c1); Arrays.sort(c2); boolean isAnagram = Arrays.equals(c1, c2); // Method 2: Frequency Array (O(n) - Best for ASCII) int[] count = new int[26]; for (char c : s1.toCharArray()) count[c - 'a']++; for (char c : s2.toCharArray()) count[c - 'a']--; boolean isAnagramFreq = true; for (int i : count) { if (i != 0) { isAnagramFreq = false; break; } }

🎯 Key Takeaways to Remember Forever

The 10 Commandments of Strings:
  1. Immutable: Can't change, only create new strings
  2. Zero-indexed: First character at index 0
  3. Slicing is exclusive: s[1:4] = indices 1, 2, 3
  4. Use join() not +: For concatenating multiple strings
  5. Case matters: "Hello" != "hello"
  6. f-strings are best: For formatting in Python 3.6+
  7. in operator: Fast substring/character checking
  8. Reverse with [::-1]: Simplest way to reverse
  9. Count frequency: Use Counter or dictionary
  10. Validate input: Check length and bounds

📊 Time Complexity Cheat Sheet

Operation Time Complexity Notes

Search (in) O(n) Linear search through string
Concatenation (+) O(n + m) Creates new string

split() O(n) Creates list of strings
join() O(n) Concatenates list efficiently

🚀 Introduction to Graphs

What is a Graph?

A Graph is a non-linear data structure consisting of vertices (nodes) connected by edges. Unlike trees, graphs can have cycles and multiple paths between nodes.

Graph Example

      A --- B
      |  /  |
      | /   |
      C --- D

Vertices: {A, B, C, D}
Edges: {(A,B), (A,C), (B,C), (B,D), (C,D)}

Graph Terminology

  • Vertex/Node: A point in the graph
  • Edge: Connection between two vertices
  • Directed Graph (Digraph): Edges have direction (A→B)
  • Undirected Graph: Edges have no direction (A—B)
  • Weighted Graph: Edges have weights/costs
  • Degree: Number of edges connected to vertex
  • Path: Sequence of vertices connected by edges
  • Cycle: Path that starts and ends at same vertex
  • Connected Graph: Path exists between any two vertices
  • DAG: Directed Acyclic Graph (no cycles)

Graph Representation

1. Adjacency Matrix

2D array where matrix[i][j] = 1 if edge exists between i and j

  • Space: O(V²)
  • Check Edge: O(1)
  • Find Neighbors: O(V)
  • Good for: Dense graphs
Python - Adjacency Matrix
# Graph with 4 vertices graph = [ [0, 1, 1, 0], # A connects to B, C [1, 0, 1, 1], # B connects to A, C, D [1, 1, 0, 1], # C connects to A, B, D [0, 1, 1, 0] # D connects to B, C ] # Check if edge exists has_edge = graph[0][1] == 1 # A-B edge exists

2. Adjacency List

Dictionary/array where each vertex stores list of neighbors

  • Space: O(V + E)
  • Check Edge: O(degree)
  • Find Neighbors: O(1)
  • Good for: Sparse graphs (most real-world)
Python - Adjacency List
from collections import defaultdict # Adjacency list representation graph = { 'A': ['B', 'C'], 'B': ['A', 'C', 'D'], 'C': ['A', 'B', 'D'], 'D': ['B', 'C'] } # Or using defaultdict graph = defaultdict(list) graph['A'].extend(['B', 'C']) graph['B'].extend(['A', 'C', 'D']) # Check neighbors neighbors_of_A = graph['A'] # ['B', 'C']
💡 Memory Trick: Graph = Social Network
  • Vertices = People
  • Edges = Friendships
  • Directed = Following (Twitter)
  • Undirected = Friends (Facebook)
  • Weighted = Strength of relationship

Graph Types & Applications

Graph Type Properties Real-World Example
Undirected Bidirectional edges Facebook friends, road network
Directed One-way edges Twitter follows, web pages
Weighted Edges have costs Road distances, flight prices
DAG Directed, no cycles Task dependencies, course prereqs

Common Graph Problems

  • Traversal: Visit all vertices (BFS, DFS)
  • Shortest Path: Find minimum cost path (Dijkstra, Bellman-Ford)
  • Minimum Spanning Tree: Connect all vertices with min cost (Prim, Kruskal)
  • Cycle Detection: Check if graph has cycles
  • Connectivity: Check if graph is connected
  • Topological Sort: Order vertices in DAG
  • Strongly Connected Components: Find groups of mutually reachable vertices

🔍 Graph Traversal: BFS & DFS

1. Breadth-First Search (BFS)

BFS explores graph level by level, visiting all neighbors before moving deeper. Uses a queue.

Use Cases: Shortest path in unweighted graph, level-order traversal, peer-to-peer networks

🔑 Key Idea: BFS finds shortest path in unweighted graphs because it explores all nodes at distance k before exploring nodes at distance k+1.
Python - BFS Implementation
from collections import deque def bfs(graph, start): """ BFS traversal of graph Time: O(V + E), Space: O(V) """ visited = set() queue = deque([start]) visited.add(start) result = [] while queue: vertex = queue.popleft() result.append(vertex) # Visit all neighbors for neighbor in graph[vertex]: if neighbor not in visited: visited.add(neighbor) queue.append(neighbor) return result # Example graph graph = { 'A': ['B', 'C'], 'B': ['A', 'D', 'E'], 'C': ['A', 'F'], 'D': ['B'], 'E': ['B', 'F'], 'F': ['C', 'E'] } print(bfs(graph, 'A')) # ['A', 'B', 'C', 'D', 'E', 'F']
Python - BFS Shortest Path
def bfs_shortest_path(graph, start, goal): """ Find shortest path using BFS Returns path and distance """ if start == goal: return [start], 0 visited = {start} queue = deque([(start, [start])]) while queue: vertex, path = queue.popleft() for neighbor in graph[vertex]: if neighbor == goal: return path + [neighbor], len(path) if neighbor not in visited: visited.add(neighbor) queue.append((neighbor, path + [neighbor])) return None, -1 # No path found path, distance = bfs_shortest_path(graph, 'A', 'F') print(f"Path: {' -> '.join(path)}, Distance: {distance}")

2. Depth-First Search (DFS)

DFS explores as deep as possible before backtracking. Uses a stack (or recursion).

Use Cases: Detect cycles, topological sort, maze solving, pathfinding

Python - DFS Recursive
def dfs_recursive(graph, vertex, visited=None): """ DFS traversal (recursive) Time: O(V + E), Space: O(V) """ if visited is None: visited = set() visited.add(vertex) result = [vertex] for neighbor in graph[vertex]: if neighbor not in visited: result.extend(dfs_recursive(graph, neighbor, visited)) return result print(dfs_recursive(graph, 'A')) # ['A', 'B', 'D', 'E', 'F', 'C']
Python - DFS Iterative
def dfs_iterative(graph, start): """ DFS traversal (iterative using stack) Time: O(V + E), Space: O(V) """ visited = set() stack = [start] result = [] while stack: vertex = stack.pop() if vertex not in visited: visited.add(vertex) result.append(vertex) # Add neighbors in reverse to maintain order for neighbor in reversed(graph[vertex]): if neighbor not in visited: stack.append(neighbor) return result print(dfs_iterative(graph, 'A'))

BFS vs DFS Comparison

Feature BFS DFS
Data Structure Queue Stack / Recursion
Strategy Level by level Deep first, then backtrack
Shortest Path Yes (unweighted) No
Time O(V + E) O(V + E)
Space O(V) - wide graphs worse O(h) - deep graphs worse
Complete Yes No (infinite graphs)
Best For Shortest path, level order Cycle detection, topological sort

Cycle Detection

Python - Detect Cycle (DFS)
def has_cycle_undirected(graph): """ Detect cycle in undirected graph using DFS """ visited = set() def dfs(node, parent): visited.add(node) for neighbor in graph[node]: if neighbor not in visited: if dfs(neighbor, node): return True elif neighbor != parent: # Found back edge (cycle) return True return False # Check all components for vertex in graph: if vertex not in visited: if dfs(vertex, None): return True return False def has_cycle_directed(graph): """ Detect cycle in directed graph Use recursion stack to detect back edges """ WHITE, GRAY, BLACK = 0, 1, 2 color = {vertex: WHITE for vertex in graph} def dfs(node): color[node] = GRAY # Currently processing for neighbor in graph.get(node, []): if color[neighbor] == GRAY: return True # Back edge found if color[neighbor] == WHITE: if dfs(neighbor): return True color[node] = BLACK # Finished processing return False for vertex in graph: if color[vertex] == WHITE: if dfs(vertex): return True return False

🛣️ Shortest Path Algorithms

1. Dijkstra's Algorithm

Dijkstra's Algorithm finds shortest path from source to all vertices in weighted graph with non-negative weights.

Strategy: Greedy - always pick unvisited vertex with smallest distance

Time Complexity:
  • Using min-heap: O((V + E) log V)
  • Using array: O(V²)
Python - Dijkstra's Algorithm
import heapq def dijkstra(graph, start): """ Dijkstra's shortest path algorithm graph: {vertex: [(neighbor, weight), ...]} Returns: distances dict and predecessors """ distances = {vertex: float('inf') for vertex in graph} distances[start] = 0 predecessors = {vertex: None for vertex in graph} # Min heap: (distance, vertex) pq = [(0, start)] visited = set() while pq: current_dist, current = heapq.heappop(pq) if current in visited: continue visited.add(current) # Check all neighbors for neighbor, weight in graph[current]: distance = current_dist + weight # Found shorter path if distance < distances[neighbor]: distances[neighbor] = distance predecessors[neighbor] = current heapq.heappush(pq, (distance, neighbor)) return distances, predecessors def reconstruct_path(predecessors, start, goal): """Reconstruct path from predecessors""" path = [] current = goal while current is not None: path.append(current) current = predecessors[current] path.reverse() return path if path[0] == start else None # Example: Weighted graph graph = { 'A': [('B', 4), ('C', 2)], 'B': [('A', 4), ('C', 1), ('D', 5)], 'C': [('A', 2), ('B', 1), ('D', 8), ('E', 10)], 'D': [('B', 5), ('C', 8), ('E', 2)], 'E': [('C', 10), ('D', 2)] } distances, preds = dijkstra(graph, 'A') print("Distances from A:", distances) print("Path A to E:", reconstruct_path(preds, 'A', 'E')) # Output: Path A to E: ['A', 'C', 'B', 'D', 'E']
⚠️ Dijkstra's Limitation: Cannot handle negative edge weights! Use Bellman-Ford for graphs with negative weights.

2. Bellman-Ford Algorithm

Bellman-Ford finds shortest paths even with negative weights. Can also detect negative cycles.

Strategy: Relax all edges V-1 times

Python - Bellman-Ford Algorithm
def bellman_ford(vertices, edges, start): """ Bellman-Ford shortest path algorithm vertices: list of vertices edges: list of (u, v, weight) tuples Returns: distances dict or None if negative cycle exists Time: O(VE), Space: O(V) """ distances = {v: float('inf') for v in vertices} distances[start] = 0 predecessors = {v: None for v in vertices} # Relax edges V-1 times for _ in range(len(vertices) - 1): for u, v, weight in edges: if distances[u] + weight < distances[v]: distances[v] = distances[u] + weight predecessors[v] = u # Check for negative cycles for u, v, weight in edges: if distances[u] + weight < distances[v]: print("Negative cycle detected!") return None, None return distances, predecessors # Example with negative weights vertices = ['A', 'B', 'C', 'D', 'E'] edges = [ ('A', 'B', 4), ('A', 'C', 2), ('B', 'C', -3), # Negative weight! ('C', 'D', 2), ('C', 'E', 3), ('D', 'E', -1) ] distances, preds = bellman_ford(vertices, edges, 'A') if distances: print("Distances from A:", distances)

3. Floyd-Warshall Algorithm

Floyd-Warshall finds shortest paths between all pairs of vertices. Works with negative weights but not negative cycles.

Strategy: Dynamic Programming - consider all intermediate vertices

Python - Floyd-Warshall Algorithm
def floyd_warshall(vertices, edges): """ Floyd-Warshall all-pairs shortest path Returns: distance matrix Time: O(V³), Space: O(V²) """ n = len(vertices) vertex_to_index = {v: i for i, v in enumerate(vertices)} # Initialize distance matrix INF = float('inf') dist = [[INF] * n for _ in range(n)] # Distance from vertex to itself is 0 for i in range(n): dist[i][i] = 0 # Fill in edge weights for u, v, weight in edges: i, j = vertex_to_index[u], vertex_to_index[v] dist[i][j] = weight # Floyd-Warshall: try all intermediate vertices for k in range(n): for i in range(n): for j in range(n): # Can we improve path from i to j through k? dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]) # Check for negative cycles for i in range(n): if dist[i][i] < 0: print("Negative cycle detected!") return None return dist, vertices # Example vertices = ['A', 'B', 'C', 'D'] edges = [ ('A', 'B', 3), ('A', 'C', 8), ('A', 'D', 7), ('B', 'C', 2), ('D', 'A', 2), ('D', 'B', 1) ] dist, verts = floyd_warshall(vertices, edges) if dist: print("\nAll-pairs shortest distances:") for i, v1 in enumerate(verts): for j, v2 in enumerate(verts): if dist[i][j] != float('inf'): print(f"{v1} to {v2}: {dist[i][j]}")

Shortest Path Algorithms Comparison

Algorithm Type Negative Weights Time Complexity Use Case
Dijkstra Single-source ❌ No O((V+E) log V) GPS, network routing
Bellman-Ford Single-source ✅ Yes O(VE) Currency exchange, negative weights
Floyd-Warshall All-pairs ✅ Yes O(V³) Small graphs, transitive closure
BFS Single-source N/A (unweighted) O(V+E) Unweighted graphs

🌲 Minimum Spanning Tree (MST)

What is MST?

A Minimum Spanning Tree is a subset of edges that connects all vertices with minimum total edge weight, forming a tree (no cycles).

Applications: Network design, circuit wiring, clustering

MST Properties:
  • Contains V-1 edges (where V = vertices)
  • No cycles (it's a tree)
  • Connects all vertices
  • Has minimum total weight

1. Prim's Algorithm

Prim's Algorithm grows MST one vertex at a time, always adding cheapest edge that connects tree to new vertex.

Strategy: Greedy - start from any vertex, keep adding minimum edge

Python - Prim's Algorithm
import heapq def prims_mst(graph, start): """ Prim's algorithm for MST graph: {vertex: [(neighbor, weight), ...]} Returns: MST edges and total weight Time: O((V+E) log V), Space: O(V) """ mst_edges = [] total_weight = 0 visited = set([start]) # Min heap: (weight, from_vertex, to_vertex) edges = [(weight, start, neighbor) for neighbor, weight in graph[start]] heapq.heapify(edges) while edges and len(visited) < len(graph): weight, u, v = heapq.heappop(edges) if v in visited: continue # Add edge to MST visited.add(v) mst_edges.append((u, v, weight)) total_weight += weight # Add new edges to heap for neighbor, edge_weight in graph[v]: if neighbor not in visited: heapq.heappush(edges, (edge_weight, v, neighbor)) return mst_edges, total_weight # Example graph graph = { 'A': [('B', 2), ('C', 3)], 'B': [('A', 2), ('C', 1), ('D', 1)], 'C': [('A', 3), ('B', 1), ('D', 4)], 'D': [('B', 1), ('C', 4), ('E', 2)], 'E': [('D', 2)] } mst, weight = prims_mst(graph, 'A') print("MST edges:", mst) print("Total weight:", weight) # Output: MST edges: [('A', 'B', 2), ('B', 'C', 1), ('B', 'D', 1), ('D', 'E', 2)] # Total weight: 6

2. Kruskal's Algorithm

Kruskal's Algorithm sorts all edges by weight and adds them one by one if they don't create a cycle.

Strategy: Greedy - process edges in order, use Union-Find to detect cycles

Python - Kruskal's Algorithm
class UnionFind: """Union-Find data structure for Kruskal's""" def __init__(self, vertices): self.parent = {v: v for v in vertices} self.rank = {v: 0 for v in vertices} def find(self, x): """Find root with path compression""" if self.parent[x] != x: self.parent[x] = self.find(self.parent[x]) return self.parent[x] def union(self, x, y): """Union by rank""" root_x = self.find(x) root_y = self.find(y) if root_x == root_y: return False if self.rank[root_x] < self.rank[root_y]: self.parent[root_x] = root_y elif self.rank[root_x] > self.rank[root_y]: self.parent[root_y] = root_x else: self.parent[root_y] = root_x self.rank[root_x] += 1 return True def kruskals_mst(vertices, edges): """ Kruskal's algorithm for MST edges: list of (u, v, weight) tuples Returns: MST edges and total weight Time: O(E log E), Space: O(V) """ # Sort edges by weight edges.sort(key=lambda x: x[2]) uf = UnionFind(vertices) mst_edges = [] total_weight = 0 for u, v, weight in edges: # Add edge if it doesn't create cycle if uf.union(u, v): mst_edges.append((u, v, weight)) total_weight += weight # Stop if we have V-1 edges if len(mst_edges) == len(vertices) - 1: break return mst_edges, total_weight # Example vertices = ['A', 'B', 'C', 'D', 'E'] edges = [ ('A', 'B', 2), ('A', 'C', 3), ('B', 'C', 1), ('B', 'D', 1), ('C', 'D', 4), ('D', 'E', 2) ] mst, weight = kruskals_mst(vertices, edges) print("MST edges:", mst) print("Total weight:", weight)

Prim's vs Kruskal's

Feature Prim's Kruskal's
Strategy Grows tree from vertex Adds edges in sorted order
Data Structure Min heap Union-Find
Time O((V+E) log V) O(E log E)
Good For Dense graphs Sparse graphs
Implementation Slightly simpler Requires Union-Find

📋 Topological Sort

What is Topological Sort?

Topological Sort is a linear ordering of vertices in a DAG where for every edge u→v, u comes before v in the ordering.

Applications: Task scheduling, course prerequisites, build systems

🔑 Important: Topological sort only exists for DAGs (Directed Acyclic Graphs). If graph has cycle, no valid ordering exists.

Example: Course Prerequisites

Math101 → Math201 → Math301
   ↓
CS101 → CS201
   ↓
Physics

Topological Order: Math101, CS101, Physics, Math201, CS201, Math301
(Many valid orderings possible!)

Method 1: DFS-based (Most Common)

Python - Topological Sort (DFS)
def topological_sort_dfs(graph): """ Topological sort using DFS Returns: ordered list or None if cycle exists Time: O(V+E), Space: O(V) """ WHITE, GRAY, BLACK = 0, 1, 2 color = {vertex: WHITE for vertex in graph} result = [] def dfs(vertex): """Returns False if cycle detected""" color[vertex] = GRAY # Currently processing for neighbor in graph.get(vertex, []): if color[neighbor] == GRAY: # Back edge - cycle detected! return False if color[neighbor] == WHITE: if not dfs(neighbor): return False color[vertex] = BLACK # Finished result.append(vertex) # Add to result return True # Process all vertices for vertex in graph: if color[vertex] == WHITE: if not dfs(vertex): return None # Cycle detected return result[::-1] # Reverse for correct order # Example: Course prerequisites courses = { 'Math101': ['Math201'], 'Math201': ['Math301'], 'Math301': [], 'CS101': ['CS201'], 'CS201': [], 'Physics': [] } order = topological_sort_dfs(courses) print("Course order:", order) # Output: ['Math101', 'Math201', 'Math301', 'CS101', 'CS201', 'Physics']

Method 2: Kahn's Algorithm (BFS-based)

Kahn's Algorithm repeatedly removes vertices with no incoming edges.

Python - Kahn's Algorithm
from collections import deque, defaultdict def topological_sort_kahns(vertices, edges): """ Kahn's algorithm for topological sort edges: list of (u, v) tuples (u -> v) Returns: ordered list or None if cycle Time: O(V+E), Space: O(V) """ # Build graph and compute in-degrees graph = defaultdict(list) in_degree = {v: 0 for v in vertices} for u, v in edges: graph[u].append(v) in_degree[v] += 1 # Start with vertices having no incoming edges queue = deque([v for v in vertices if in_degree[v] == 0]) result = [] while queue: vertex = queue.popleft() result.append(vertex) # Remove edges from this vertex for neighbor in graph[vertex]: in_degree[neighbor] -= 1 if in_degree[neighbor] == 0: queue.append(neighbor) # Check if all vertices processed (no cycle) if len(result) != len(vertices): return None # Cycle exists return result # Example vertices = ['A', 'B', 'C', 'D', 'E'] edges = [('A', 'C'), ('B', 'C'), ('B', 'D'), ('C', 'E'), ('D', 'E')] order = topological_sort_kahns(vertices, edges) print("Topological order:", order) # Output: ['A', 'B', 'C', 'D', 'E'] (or ['B', 'A', 'C', 'D', 'E'])

Applications of Topological Sort

  • Build Systems: Compile files in dependency order
  • Course Scheduling: Take prerequisite courses first
  • Task Scheduling: Execute tasks with dependencies
  • Maven/NPM: Install packages with dependencies
  • Spreadsheet Formulas: Calculate cells in order
  • Database Schema: Create tables with foreign keys

🔗 Union Find (Disjoint Set)

What is Union-Find?

Union-Find (Disjoint Set Union) is a data structure that tracks elements partitioned into non-overlapping sets. Supports two main operations:

  • Find: Determine which set an element belongs to
  • Union: Merge two sets into one
🔑 Key Use Cases:
  • Kruskal's MST algorithm
  • Cycle detection in undirected graphs
  • Network connectivity
  • Image processing (connected components)

Implementation with Optimizations

Python - Union-Find with Path Compression & Union by Rank
class UnionFind: """ Optimized Union-Find with: 1. Path Compression (in find) 2. Union by Rank Both optimizations give nearly O(1) amortized time! """ def __init__(self, size): self.parent = list(range(size)) self.rank = [0] * size self.count = size # Number of disjoint sets def find(self, x): """ Find root of x with path compression Time: O(α(n)) amortized (inverse Ackermann, practically constant) """ if self.parent[x] != x: # Path compression: point directly to root self.parent[x] = self.find(self.parent[x]) return self.parent[x] def union(self, x, y): """ Union two sets by rank Returns: True if sets were merged, False if already in same set """ root_x = self.find(x) root_y = self.find(y) if root_x == root_y: return False # Already in same set # Union by rank: attach smaller tree under larger if self.rank[root_x] < self.rank[root_y]: self.parent[root_x] = root_y elif self.rank[root_x] > self.rank[root_y]: self.parent[root_y] = root_x else: self.parent[root_y] = root_x self.rank[root_x] += 1 self.count -= 1 return True def connected(self, x, y): """Check if x and y are in same set""" return self.find(x) == self.find(y) def get_count(self): """Return number of disjoint sets""" return self.count # Example: Network connectivity uf = UnionFind(6) # 6 nodes: 0,1,2,3,4,5 # Connect some nodes uf.union(0, 1) uf.union(1, 2) uf.union(3, 4) print(f"0 and 2 connected: {uf.connected(0, 2)}") # True print(f"0 and 3 connected: {uf.connected(0, 3)}") # False print(f"Number of components: {uf.get_count()}") # 3

Applications

1. Detect Cycle in Undirected Graph

Python - Cycle Detection
def has_cycle_uf(n, edges): """ Detect cycle using Union-Find n: number of vertices (0 to n-1) edges: list of (u, v) tuples """ uf = UnionFind(n) for u, v in edges: # If u and v already in same set, adding edge creates cycle if not uf.union(u, v): return True return False # Example edges = [(0, 1), (1, 2), (2, 0)] # Forms a cycle print(f"Has cycle: {has_cycle_uf(3, edges)}") # True

2. Number of Connected Components

Python - Count Components
def count_components(n, edges): """ Count number of connected components """ uf = UnionFind(n) for u, v in edges: uf.union(u, v) return uf.get_count() # Example edges = [(0, 1), (1, 2), (3, 4)] print(f"Components: {count_components(5, edges)}") # 2

3. Friend Circles

def find_circle_num(is_friend): """ Find number of friend circles is_friend[i][j] = 1 if i and j are friends Problem: Count number of disjoint friend groups """ n = len(is_friend) uf = UnionFind(n) for i in range(n): for j in range(i + 1, n): if is_friend[i][j] == 1: uf.union(i, j) return uf.get_count() # Example friends = [ [1, 1, 0], [1, 1, 0], [0, 0, 1] ] print(f"Friend circles: {find_circle_num(friends)}") # 2

Time Complexity Analysis

Operation Without Optimization With Optimizations
Find O(n) worst case O(α(n)) amortized ≈ O(1)
Union O(n) worst case O(α(n)) amortized ≈ O(1)
Connected O(n) worst case O(α(n)) amortized ≈ O(1)
💡 Union-Find Optimizations:
  • Path Compression: Make tree flat during find
  • Union by Rank: Always attach smaller tree to larger
  • Together: Give nearly constant time operations!
  • α(n): Inverse Ackermann function, grows extremely slowly (< 5 for all practical n)

Key Takeaways

Remember:
  • BFS: Queue, level-by-level, shortest path in unweighted
  • DFS: Stack/recursion, go deep, detect cycles
  • Dijkstra: Min-heap, greedy, NO negative weights
  • Bellman-Ford: Relaxation, handles negative, slower
  • MST: Prim (vertex-based) or Kruskal (edge-based)
  • Topological: Only for DAGs, many valid orderings
  • Union-Find: Near constant time with optimizations
